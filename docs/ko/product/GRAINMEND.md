# GrainMend

[문서 홈](../README.md)

GrainMend는 필름의 먼지와 핀홀, 스크래치와 유제 손상을 복원하며 원본 파일을 그대로 보존한 채 복원 내역을 순서가 있는 편집 기록으로 저장합니다.

| 도구 | 보는 범위 | 복원 방식 |
|---|---|---|
| 자동 | 이미지 전 영역 | 확신하는 결함만 보수적으로 |
| 가이드 | 직접 고른 영역 | 작은 티끌과 희미한 결함까지 꼼꼼히 |
| 브러시 | 칠한 자리 | 주변 구조와 질감을 가져와 채움 |
| 복제 도장 | 직접 고른 원본 지점 | 고정된 오프셋으로 실제 원본 픽셀을 복사 |
| IR | 스캐너의 적외선 채널 | 부분 차폐는 광학 투과율 나눗셈(`raw ÷ (1 − attenuation)`, 최대 2배 증폭)으로 직접 복원하고, 불투명 중심부(`>= 50%`)만 RGB 패치 복원기로 넘김 |

현상 화면에는 자동과 가이드, 브러시와 복제 도장 도구가 있습니다. 플러그인이 기능을 보고하면 스캔 단계에서 IR을 켤 수 있고, 스캔이 끝나면 그 결과가 GrainMend 편집 목록에 함께 들어옵니다.

> [!CAUTION]
> GrainMend RGB는 하드웨어 IR 청소와 다른 가시광 방식으로 동작하며, GrainMend IR 또한 Digital ICE와 iSRD, SRDx와는 독립된 자체 알고리즘으로 작동합니다.

## 어려운 점

필름의 결함과 사진의 구조는 한 픽셀에 겹쳐 있습니다.

- 먼지는 작고 불규칙한 밝거나 어두운 얼룩으로 나타납니다.
- 핀홀은 고립된 강한 점 형태를 띱니다.
- 스크래치는 길고 가늘지만 전선이나 문틀, 글자도 모양이 비슷합니다.
- 유제 손상은 색과 질감을 함께 바꿉니다.
- 고해상도에서는 필름 그레인이 작은 결함만큼 커집니다.

고주파 성분을 통째로 지우면 먼지와 함께 그레인과 가장자리까지 사라지므로 GrainMend는 검출과 분류, 복원과 저장 단계로 나누어 처리합니다.

## 작업 순서

검출 마스크와 복원 결과를 분리해 보관하므로 마스크를 먼저 점검하고 원하는 결함만 골라 반영하거나 복원을 새로 계산할 수 있으며 아래 순서를 차례로 거칩니다.

1. 입력 이미지와 검사 영역, 크기를 살핍니다.
2. 결함 후보를 찾아 마스크를 다듬습니다.
3. 결함 유형을 분류합니다.
4. 사진 속 실제 구조로 판별된 후보는 복원 대상에서 걸러냅니다.
5. 가까운 곳에서 원본 패치를 찾습니다.
6. 밝기와 질감, 방향을 맞춥니다.
7. 경계를 부드럽게 섞어 줍니다.
8. 편집 기록에 반영합니다.

## 도구

### 자동

이미지 전 영역에서 신뢰도가 높은 결함만 골라내는데, 작은 티끌을 일부 남기더라도 사진의 실제 구조를 보호하는 편이 안전하기 때문입니다. 이 도구는 기본 현상 과정과 분리되어 있어 사용자가 직접 실행할 때만 편집 기록에 남습니다.

### 가이드

사각형을 그리면 그 안쪽과 주변 문맥만 분석합니다. 사용자가 결함 위치를 직접 지정한 상태이므로 자동 모드보다 작은 티끌이나 희미한 결함과 밀집한 무리를 적극적으로 찾아내며 지정한 범위보다 넓게 문맥을 읽어 복원에 참조할 주변 화소가 가장자리에서 잘리는 현상을 막습니다. 현재 최대 문맥 반경은 264픽셀입니다.

### 브러시

복원할 자리를 직접 칠하면 단색으로 덮는 대신 마스크 근처에서 어울리는 원본 패치를 탐색해 주변 구조와 질감을 채워 넣으며 알맞은 패치가 없으면 제한적으로 검출 경로를 대신 활용합니다.

### 복제 도장

Mac에서는 `⌥` 클릭, Windows에서는 `Alt` 클릭으로 원본 지점을 고른 뒤 대상 영역에 그리면 자동 검출 없이 원본과 대상의 오프셋을 유지한 채 실제 화소를 복제해 넣습니다.

편집 기록에는 브러시 지름과 경도, 좌표와 오프셋을 저장하므로 회전이나 뒤집기, 크롭 뒤에도 원래 원본 좌표에 그대로 반영됩니다. 이때 오프셋은 정수 픽셀 단위로 정렬하며 이미지 경계 밖의 영역은 제외하고 안쪽만 채웁니다.

### IR

플러그인이 실제 IR 채널을 넘겨주고 크기와 영역이 RGB와 맞을 때만 작동합니다. 부분적으로 차폐된 픽셀은 광학 감쇠 투과율 나눗셈(`raw ÷ (1 − attenuation)`, 최대 2배 증폭)으로 직접 복원해 아래의 디테일과 그레인을 지킵니다. 강하게 차단된 불투명 중심부(`>= 50%` 감쇠)만 RGB 패치 복원기로 넘깁니다.

## RGB에서 결함 찾기

### 주변과의 차이

밝기는 사진마다 달라서 전역 임계값 대신 주변 밝기와의 차이와 분산, 방향성을 함께 계산해 밝은 먼지와 어두운 결함 후보를 추출합니다.

### 마스크 정리

고립된 노이즈는 버리고 끊어진 결함은 연결한 뒤 8방향으로 맞닿은 화소를 한 덩어리로 합칩니다. 넓은 영역은 타일로 나누어 계산하더라도 타일 경계에 걸친 덩어리는 원본 이미지 좌표계에서 다시 통합합니다.

### 해상도 차이

똑같은 먼지 한 톨도 1200dpi와 7200dpi에서는 차지하는 화소 수가 다르므로 해상도 정보가 확실하면 크기 범위를 실제 물리 치수에 비례해 조정하고, 불확실하면 스캐너 모델을 추측하는 대신 보수적인 화소 기준을 따릅니다.

### 분류

덩어리마다 아래 지표를 계산합니다.

- 면적과 경계 상자
- 긴 축과 짧은 축의 비율
- 가로와 세로/대각선 방향
- 선형성과 채움 비율/주변 대비
- 가까운 가장자리와 맞닿는지
- 다른 덩어리와의 관계

분류 결과는 먼지와 핀홀을 비롯해 방향별 스크래치와 유제 손상, 미세 티끌 가운데 알맞은 유형으로 정해지며 항목마다 신뢰도도 함께 들어갑니다.

### 사진에 속한 선을 지우지 않기

전선이나 난간뿐 아니라 건물 모서리와 문틀, 글자도 스크래치로 읽으면 안 됩니다. 평행선과 그리드, 가장자리의 연속성과 장면 구조에 붙은 선은 따로 살핍니다. 자동은 오검출을 더 엄격하게 거르고 가이드는 사용자가 고른 위치도 함께 고려합니다.

## 복원

1. 결함 근처에서 마스크 바깥에 있으면서 주변 구조와 어울리는 원본 패치를 찾습니다.
2. 패치와 대상 영역의 저주파 밝기와 색 차이를 보정합니다.
3. 패치의 고주파 질감을 살려 필름 그레인 결을 자연스럽게 연결해 줍니다.
4. 긴 스크래치는 양 끝이 향하는 방향을 먼저 봅니다.
5. 마스크 가장자리에서 원본과 복원 패치를 부드럽게 섞습니다.

강도는 완성된 패치와 원본의 혼합 비율입니다.

자동 복원이 밑에 무엇이 있었는지 알 수 없는 경우가 있습니다. 참조할 만한 주변 질감이 없거나 결함이 주요 구조를 모두 덮었다면 브러시나 복제 도장, 별도의 수작업이 필요합니다.

## IR 처리

### 입력 조건

- 플러그인이 IR 기능을 명시적으로 알려 줍니다.
- RGB와 IR이 한 스캔 세션에 속합니다.
- 두 이미지의 픽셀 크기와 예상 영역이 똑같습니다.
- 파일을 읽을 수 있고 원본 ID 검사를 통과합니다.

스캐너 모델이 하드웨어 IR을 지원하는 기종이더라도 플러그인이 IR 기능을 보고할 때만 화면과 요청에서 열립니다.

### 정렬

광학계와 센서 판독 차이로 RGB와 IR이 몇 화소 어긋날 수 있으므로 전역 정렬은 먼저 IR 결함 지점을 빨강 채널의 부분 암부와 대조하고, 필요할 때 IR 누설 질감 상관으로 넘어가며 피크 신뢰도와 탐색 경계 도달 여부를 함께 기록합니다.

전역 오프셋은 참고용 시작 시드로만 삼으며, 전역 정렬의 신뢰도가 낮거나 탐색 상한에 걸리면 `(0, 0)`에서 출발해 강한 후보들로 대략적인 합의 오프셋을 투표로 구한 뒤 각 결함을 가시광 빨강 채널과 개별 정렬해 확인(`>= 4σ`)하고 미확인 후보는 모두 버립니다.

### 장면 패턴 빼기

필름 염료와 은 농도가 적외선 채널에 비쳐 나올 수 있으므로 GrainMend IR은 네 단계로 실제 결함과 장면 잔상을 구분합니다.

1. 이미지 외곽과 맞닿은 어두운 필름 홀더와 가장자리 여백(rebate) 영역을 플러드 필로 먼저 제외합니다.
2. 주변 영역의 형태학 그레이스케일 닫힘 바탕 곡선(`localBaseline`)을 세워 좁은 결함은 메워 넘기고 넓은 시안 염료 장면 잔상은 바탕 곡선에 흡수시킵니다.
3. IR 입력을 광학 농도 `log(baseline / value)`로 바꿉니다.
4. 스캔의 중앙값과 사분위 범위(IQR)로 깨끗한 필름의 바닥 농도와 `σ`를 추정한 뒤 면적 비례 유의도 `Σ(density − floor) ≥ mσ·√area`를 넘는 후보를 모으고, 각 후보를 가시광 빨강 채널에서 부분 대조(`>= 4σ`)해 확인한 다음 히스테리시스로 마스크를 넓힙니다.

### 안전 조건

- 비정상적으로 넓은 마스크는 복원 단계에서 걸러냅니다.
- 가시광 빨강 채널에서 부분 정렬과 확인(`>= 4σ`)을 통과한 후보만 유지합니다.
- 염료 상으로 기록되는 컬러 필름(컬러 네거티브와 컬러 슬라이드/포지티브)은 자동 IR이 켜지고 은 입자 상으로 이루어진 흑백 필름은 차단됩니다.
- 코다크롬과 특수 유제는 `FilmType`만으로 식별하기 어려우므로 필요할 때 IR을 수동으로 끕니다.

상용 IR 도구 역시 일반 흑백과 코다크롬에는 별도 제약을 둡니다.

- [SilverFast: iSRD dust and scratch removal](https://www.silverfast.com/about-silverfast-why-scanning-basics-of-scanning/why-silverfast/silverfast-feature-highlights/isrd-dust-scratches-removal-eliminate-defects-with-infrared-channel/)

GrainMend IR은 상용 도구와 독립적으로 설계된 자체 파이프라인이며 필름별 IR 제약과 정렬 실패 조건은 [GrainMend IR이 피해야 할 필름](../reference/INFRARED_LIMITS.md)에 정리했습니다.

## 편집 기록과 저장

자동과 가이드뿐 아니라 브러시와 복제 도장, IR까지 순서가 있는 편집 목록 한 개를 공유합니다.

항목별 저장 내용:

- ID와 종류
- 반영 순서
- 켜짐 여부와 강도
- 영역과 마스크/복제 원본 오프셋
- 결함 분류와 진단 수치
- 원본 프레임과 편집 버전
- 복원된 패치, 또는 다시 만드는 데 필요한 설정

앞선 복원 결과가 뒤따르는 단계의 입력을 바꾸므로 목록의 순서도 편집 기록의 일부입니다.

원본 파일은 항상 읽기 전용으로 보존하고 GrainMend 기록은 앱이 관리하는 사이드카에 따로 저장합니다. 이때 원본 SHA-256, 편집 버전, 기록 지문으로 입력 무결성을 검증하며 사이드카가 없거나 손상되면 파생 캐시를 원본 대신 참조하는 동작을 막습니다.

GrainMend 캐시는 빠른 화면 표시와 재렌더링을 위한 파생 파일이므로 파일이 없거나 검증에 실패하면 원본과 편집 기록에서 새로 생성하며, 내보내기에 필요한 복원 결과를 재구성할 수 없으면 원본으로 대체하는 대신 내보내기를 즉시 중단시킵니다.

## 성능

- 작은 편집은 결함과 그 주변 문맥만 다시 계산합니다.
- 넓은 영역은 경계 여유를 둔 겹치는 타일로 나눕니다.
- 결과는 타일끼리 겹치는 가장자리를 뺀 중앙 영역에서만 모읍니다.
- 타일은 한 번에 최대 4개까지 병렬로 처리합니다.
- `CleanedRawCanvas`는 바뀐 사각형만 복사합니다.
- 실행 취소용 복사본은 실제 수정이 일어나기 전까지 메모리 버퍼를 공유 상태로 유지시킵니다.
- 메모리가 부족하면 다시 만들 수 있는 이미지와 패치 캐시를 버립니다.

실제 시간은 해상도, 결함 수, 영역 크기, 하드웨어에 따라 달라집니다.

2026-07-25에 Mac14,3(arm64와 메모리 24GiB)의 macOS 26.5 환경에서 macOS Release 빌드로 측정한 결과입니다.

| 경로 | 입력 | 결과 |
|---|---|---:|
| 가이드 검출 | 1600×1600, 먼지 25개 | 0.35초, 25개 검출 |
| 부분 ROI 검출 | 1600×1600 | 0.38초 |
| 가이드 고밀도 부하 | 1280×960, 8장 × 3회 | 중앙값 0.423초, p95 0.488초, 최대 0.526초 |
| IR 검출(2026년 8월 개편 이전) | 6000×4000, 24MP | 1.042초, 메모리 증가 최대 249.2 MiB |

위의 IR 검출 수치는 2026년 8월 닫힘 바탕 곡선과 감쇠 복원 개편 이전에 측정한 결과입니다. 고밀도 부하 24회에서 결함 위치의 마스크 반영률 최저는 99.80%, 평균 잔차 오차 최고는 2.70/255였습니다.

이는 macOS의 합성 입력 회귀 참조치이며 Windows도 C++(`negaflow-windows/src/Native/imaging/`)에서 똑같은 GrainMend RGB와 IR 파이프라인을 그대로 따릅니다.

## 벤치마크

`defect-bench`는 아래 파일과 지표를 만들어 냅니다.

- 원본, 복원 결과, 차이, 마스크 이미지
- 100% 크롭
- 검출 수와 신뢰도
- 처리 시간
- 기준 이미지가 있으면 PSNR과 절대 오차

```bash
swift run -c release negaflow defect-bench <input-dir> \
  --reference-dir <reference-dir> \
  --out <report-dir>
```

RGB 회귀에는 FILM-R v2의 손상본과 전문가 복원본 쌍 44개를 활용합니다.

- 데이터셋: Authentically damaged & manually restored film scans (FILM-R v2)
- 저자: Daniela Ivanova
- DOI: <https://doi.org/10.6084/m9.figshare.21803304.v2>
- 라이선스: CC BY 4.0 (<https://creativecommons.org/licenses/by/4.0/>)
- 쌍: 44
- 총 용량: 437,570,872 bytes

자동 경로에는 민감도 0.7과 과검출 안전선이 들어갑니다. FILM-R 44쌍에서 34장이 좋아지고 6장이 나빠졌습니다. 평균 PSNR 변화는 +0.466 dB, 최악의 경우는 −1.338 dB, 가중 악화 픽셀은 0.017%입니다.

자동 모드는 후보가 지나치게 많으면 과검출을 막기 위해 실행을 멈추고 가이드 도구를 안내하는 반면, 사용자가 직접 범위를 지정하는 가이드, 브러시, 복제 도장, IR은 이 상한 없이 그대로 실행됩니다. 44쌍 가운데 6장은 전문가 수작업 복원보다 PSNR이 낮으며 이 벤치마크는 가시광 자동 복원의 회귀 참조치일 뿐 실제 스캐너의 하드웨어 IR 품질을 대신 보증하지는 않습니다.

## 시험 범위

- 8방향 연결성과 마스크
- 형태학 연산
- 먼지와 스크래치/미세 티끌 검출
- 선과 그리드를 오검출로 거르기
- 넓은 영역의 타일 경계
- 방향별 스크래치 복원
- 주변 질감과 밝기 보정
- 브러시 마스크
- 복제 도장의 오프셋과 경도/패치 합성
- IR 정렬과 바탕 곡선, 결함 군집과 메모리 상한
- 원본 단계에 반영하는 처리와 앱 편집 기록의 렌더링
- 반복 반영과 실행 취소
- 화면을 오가는 동안의 프레임 소유권

일부 대용량 성능 시험은 전용 환경 변수를 지정했을 때만 실행하므로 기본 테스트 스위트와는 별도로 검증합니다.

## 이름과 상표

`GrainMend`는 negaflow 고유의 기능 이름입니다.

- `Digital ICE`는 Eastman Kodak Company나 관련 권리자의 상표일 수 있습니다.
- `iSRD`, `SRDx`, `SilverFast`는 LaserSoft Imaging의 상표입니다.
- 이 명칭들은 기술 비교와 제품 식별 목적으로만 언급합니다.
- GrainMend는 제3자 기술과 제휴나 호환 관계가 없는 독립된 자체 구현입니다.
