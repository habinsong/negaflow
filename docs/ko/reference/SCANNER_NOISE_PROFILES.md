# 스캐너 노이즈 프로파일

[문서 홈](../README.md)

평범한 사진 한 장으로는 노이즈 프로파일을 만들 수 없습니다. 사진의 고주파 성분에는 피사체와 필름 그레인이 섞여 있기 때문입니다.

균일하거나 계단형인 타깃을 같은 설정으로 세 번 이상 스캔합니다. 같은 위치의 픽셀 값이 변하는 정도가 신호 수준별 분산이 됩니다.

- [ISO 15739:2023](https://www.iso.org/standard/82233.html)은 디지털 영상 장치의 신호별 노이즈를 재고 보고하는 방법을 정합니다.
- [ISO 21550:2004](https://www.iso.org/standard/35939.html)은 투과·반사 스캐너의 다이내믹 레인지를 재는 방법을 정합니다.

ISO 15739는 디지털 카메라용입니다. negaflow는 스캐너가 이 규격에 속한다고 주장하지 않고 반복 측정과 신호별 분산이라는 발상만 빌립니다.

> [!NOTE]
> 지금 번들에는 `holdoutValidated` 장치 노이즈 프로파일이 없어서 자동으로 적용되는 것이 없습니다. 기존 프로파일의 질감 수치는 센서 노이즈 자료로 쓰지 않습니다.

## 프로파일 하나의 범위

`ScannerNoiseProfile`은 아래가 모두 같을 때만 맞는 것으로 봅니다.

- 스캐너 제조사와 모델
- 해상도(DPI)
- 채널당 비트 심도
- 색 모드
- 멀티 노출 사용 여부

비슷한 모델이나 다른 해상도의 값은 빌리지 않습니다. 정확히 맞는 자동 프로파일이 둘 이상이면 하나를 고르지 않고 실패합니다.

같은 장면의 선형 RGB 스캔 세 장 이상에서 채널별로 아래 식을 맞춥니다.

```math
\operatorname{variance}(x) = m_{\mathrm{shot}}x + b_{\mathrm{read}}
```

프로파일에는 이것도 기록합니다.

- 보정 자료의 SHA-256
- 측정한 프레임 수와 샘플 수
- 관측한 신호 범위
- 회귀 R²
- 검증된 노이즈 감소 강도

코드의 최대 강도는 계산이 망가지는 것을 막을 뿐 품질 합격선이 아닙니다.

## 상태

| 상태 | 뜻 | 자동 적용 |
|---|---|---|
| `draft` | 측정이나 조정이 끝나지 않음 | 아니오 |
| `measured` | 실제 장치에서 반복 측정함, 독립 검증 없음 | 아니오 |
| `holdoutValidated` | 별도 검증 자료로 강도를 확인함 | 정확히 일치할 때만 |

자동 사용에는 일치하는 `holdoutValidated` 프로파일이 정확히 하나 있어야 하고, 보정·검증 자료의 SHA-256과 파일 구조 검사도 통과해야 합니다. `draft`와 `measured`는 기존 일반 설정을 바꾸지 못합니다.

## 현재 상태

저장소의 NORITSU, SP-3000 컬러 프로파일에는 실제 장면에서 얻은 `texture` 값이 있습니다. 이 값에는 피사체, 초점, 필름 그레인이 섞여 있어 센서 노이즈 자료로 쓸 수 없습니다.

반복 촬영한 균일 타깃과 별도 검증 자료는 아직 없습니다. 검증된 장치 노이즈 프로파일은 번들에 없고 자동 경로는 기존 일반 설정을 씁니다.

실제 프로파일에는 아래가 모두 필요합니다.

1. 같은 장치, 해상도, 비트 심도, 색 모드, 멀티 노출 설정의 선형 스캔 세 장 이상
2. 보정 자료의 파일 목록과 SHA-256
3. 보정에 쓰지 않은 검증 장면과 그 SHA-256
4. 노이즈 감소와 디테일·필름 그레인 보존의 비교
5. 실제 사용자의 100% 확대 확인

실제 하드웨어 캡처는 `negaflow-scanner-sane` 플러그인이 맡습니다. SANE 옵션과 장치 제어 코드는 이 저장소에 넣지 않습니다.
