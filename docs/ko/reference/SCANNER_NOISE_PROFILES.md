# 스캐너 노이즈 프로파일

[문서 홈](../README.md)

평범한 사진 한 장으로는 노이즈 프로파일을 만들 수 없습니다. 사진의 고주파 성분에는 피사체와 필름 그레인이 섞여 있기 때문입니다.

균일하거나 계단형인 타깃을 똑같은 설정으로 세 번 이상 스캔하면 각 위치의 픽셀 밝기가 흔들리는 정도가 입력 수준별 분산이 됩니다.

- [ISO 15739:2023](https://www.iso.org/standard/82233.html)은 디지털 영상 장치의 입력 수준별 노이즈를 측정하고 보고하는 방법을 규정합니다.
- [ISO 21550:2004](https://www.iso.org/standard/35939.html)은 투과와 반사 스캐너의 다이내믹 레인지 측정 절차를 보여 줍니다.

ISO 15739는 디지털 카메라용 규격이므로 negaflow는 반복 측정과 입력 수준별 분산이라는 발상만 참고합니다.

> [!NOTE]
> 지금 번들에는 `holdoutValidated` 장치 노이즈 프로파일이 없어서 자동 노이즈 프로파일은 꺼져 있으며, 기존 프로파일의 질감 수치는 질감 표현에만 활용됩니다.

## 개별 프로파일의 범위

`ScannerNoiseProfile`은 아래가 모두 같을 때만 일치하는 것으로 봅니다.

- 스캐너 제조사와 모델
- 해상도(DPI)
- 채널당 비트 심도
- 색 모드
- 멀티 노출 사용 여부

조건이 전부 일치하는 프로파일만 선택하며, 부합하는 자동 프로파일이 복수로 발견되면 오류를 반환합니다.

한 장면의 선형 RGB 스캔 세 장 이상에서 채널별로 아래 식의 계수를 찾습니다.

```math
\operatorname{variance}(x) = m_{\mathrm{shot}}x + b_{\mathrm{read}}
```

프로파일에는 아래 항목도 함께 들어갑니다.

- 보정 자료의 SHA-256
- 측정한 프레임 수와 샘플 수
- 관측한 밝기 범위
- 회귀 R²
- 검증된 노이즈 감소 강도

코드의 최대 강도는 계산 폭주를 막는 안전 상한입니다.

## 상태

| 상태 | 뜻 | 자동 적용 |
|---|---|---|
| `draft` | 측정이나 조정이 끝나지 않음 | 아니오 |
| `measured` | 실제 장치에서 반복 측정함, 독립 검증 없음 | 아니오 |
| `holdoutValidated` | 별도 검증 자료로 강도를 확인함 | 정확히 일치할 때만 |

자동 사용에는 정확히 일치하는 `holdoutValidated` 프로파일 한 개가 있어야 하고 보정과 검증 자료의 SHA-256, 파일 구조 검사도 통과해야 하며, `draft`와 `measured` 상태에서는 기존 일반 설정이 그대로 남습니다.

## 현재 상태

저장소의 NORITSU, SP-3000 컬러 프로파일에 들어 있는 `texture` 수치는 실제 장면에서 얻은 값이라 피사체와 초점, 필름 그레인이 섞여 있으므로 질감 특성에만 반영합니다.

반복 촬영한 균일 타깃과 별도 검증 자료는 아직 준비 전이라 번들은 검증된 장치 노이즈 프로파일을 비워 두고 있으며, 현상 파이프라인에서 `ScannerNoiseReduction`은 라이브러리 코드와 테스트에서 일반 `1.0` 배율로 동작하고 사용자 노이즈 감소는 `FilmScanDenoise`로 직접 켜서 바꿉니다.

실제 프로파일을 만들려면 아래 항목을 모두 갖추세요.

1. 똑같은 장치와 해상도, 비트 심도와 색 모드, 멀티 노출 설정의 선형 스캔 세 장 이상
2. 보정 자료의 파일 목록과 SHA-256
3. 보정에 포함하지 않은 검증 장면과 그 SHA-256
4. 노이즈 감소, 디테일, 필름 그레인 보존의 비교
5. 실제 사용자의 100% 확대 확인

실제 하드웨어 캡처는 별도 저장소의 `negaflow-scanner-sane` 플러그인이 맡습니다.
