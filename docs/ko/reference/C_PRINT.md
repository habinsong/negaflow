# 프린트 레이아웃과 C-print 미리보기

[문서 홈](../README.md)

프린트 화면에는 레이아웃이 여덟 가지 있어 단일 이미지와 콘택트 시트, 사진 패키지와 사용자 패키지를 비롯해 시아노타입과 유리 건판, 젤라틴 실버와 워터마크를 고를 수 있습니다.

## 콘택트 시트

- 새 콘택트 시트는 검은 시트에 6열 × 7행과 간격 2mm로 열리며 다른 레이아웃은 모두 흰 시트가 기본입니다. 레이아웃마다 시트를 검정이나 회색, 흰색으로 바꿀 수 있고 캡션과 사용자 텍스트, 재단선과 페이지 윤곽선은 대비되는 색으로 저절로 바뀝니다.
- 여백과 행열 수, 간격은 공통 물리 레이아웃 규약을 따르며, 물리적으로 배치할 수 없는 조합은 미리보기가 깨지지 않도록 가능한 가장 큰 간격으로 줄어듭니다. 자동 방향은 행열 배치를 따르고 **맞춤**은 사진 전체를 보여 주어 셀 안에 여백이 생길 수 있는 반면, **셀 채우기**는 사진을 공통 셀 비율로 잘라 여백을 고르게 맞춥니다.
- 캡션은 파일 이름이나 원본 프레임 번호, 현재 이미지 순서의 1번부터 매기는 순번과 평점, 사용자 텍스트 중에서 고릅니다. 설치된 시스템 글꼴을 선택해 미리보기와 내보내기에 똑같이 적용하며 이미지별 캡션은 왼쪽이나 가운데, 오른쪽으로 정렬됩니다. 사용자 텍스트는 독립된 상자 여러 개를 지원해 상자마다 문구와 정렬, 위치와 가로세로 크기를 따로 받습니다.

## 용지 설정과 눈금자

모든 레이아웃이 공통 용지 설정을 공유하여 3.5 × 5에서 24 × 36까지의 사진 인치 규격과 Letter, Tabloid, A3+, ISO A1–A6, ISO B1–B6을 제공합니다. 인화지 마감은 시트 색 바로 아래에 자리하며 무광(기본값)과 유광, 러스터와 실크 중에서 고릅니다.

눈금자는 기본 상태가 꺼짐이고 켜면 스위치 아래에 인치/cm 선택기가 열리며 페이지 위쪽에 가로 눈금자, 왼쪽에 세로 눈금자가 붙습니다. 정수 인치나 센티미터에 숫자가 붙고 그 사이에 작은 눈금이 들어갑니다.

## 단일 레이아웃과 고전 레이아웃

단일 이미지와 시아노타입, 유리 건판과 젤라틴 실버는 선택한 사진마다 한 페이지를 만들고 여러 장을 고르면 세로로 쌓아 보여 줍니다. 시아노타입은 휘도를 파란 단색 이미지로 바꾸는 반면 유리 건판은 단색 네거티브로, 젤라틴 실버는 무채색 단색 포지티브로 표현합니다.

이 세 스타일은 단일 이미지의 용지와 방향, 여백과 출력, 인스펙터 설정을 그대로 공유해 내보내기와 빠른 내보내기에도 똑같이 렌더링되며, 특정 고전 약품이나 건판의 화학 측정을 모사하는 대신 출발용 시각 스타일을 보여 줍니다.

## 워터마크와 레이아웃 템플릿

워터마크는 레이아웃 종류 메뉴의 독립된 항목으로, 선택하면 용지 크기가 사진 비율로 바뀌고(이후 다른 크기를 고를 수 있음) 사진 바깥에 여백 프레임이 생깁니다. 이름 위치 메뉴는 항상 열려 있어 아래 가운데나 위쪽 세 자리(왼쪽과 가운데, 오른쪽)를 지원하는데 위쪽을 고르면 상단 여백이 함께 켜집니다.

셔터 속도에는 따옴표를 생략하고 비어 있는 텍스트 칸은 공란으로 유지합니다. 이름 텍스트는 지정한 위치 안에서 가운데에 놓이며 이름과 히스토그램이 겹치는 위치에 있으면 히스토그램이 이름 위에 올라가 각각 가운데에 배치해 줍니다.

레이아웃 템플릿은 레이아웃과 용지 설정, 시트 색과 워터마크 설정을 복원한 뒤 미리보기를 새로 고치고 DPI와 눈금자 설정은 기존 상태를 지킵니다. 이 항목이 생기기 전에 저장한 템플릿은 현재의 시트 색과 워터마크를 그대로 유지합니다. 항목 배치와 DNG 원본, 색 공간 규칙은 [라이브러리에서 인화까지](../product/WORKFLOW.md)에 나와 있습니다.

## 인화 내보내기

사이드바 탭의 **내보내기**(**빠른 내보내기** 위)와 **빠른 내보내기**는 모두 Raw TIFF 외의 형식에 현재 페이지 크기와 방향, 여백과 레이아웃, 시트 색과 캡션, 사용자 텍스트와 재단선을 렌더링합니다. 두 경로 모두 지정한 형식과 DPI, 폴더와 이름 규칙을 따르고, 설정(macOS는 색 관리, Windows는 내보내기이며 프린트 > 출력 > C-print > 고급에 읽기 전용으로 표시)에서 고른 전달 색 공간을 따릅니다.

색역 경고나 소프트 프루프 시뮬레이션, 인화지 광택 마감은 화면 전용 보조 표시이며, 작업이 실행되는 동안 패널에는 완료한 페이지 수와 진행 막대, 백분율이 나타납니다.

### 페이지 수와 렌더링

출력 수는 완성된 페이지 수입니다. 사진 39장의 6 × 7 콘택트 시트는 합성한 페이지 한 장, 4장짜리 사진 패키지는 10페이지, 기본 사용자 패키지는 한 페이지로 내보내고, 단일 이미지 계열 레이아웃은 빠른 내보내기와 똑같은 제한된 배치 스케줄러로 39개 파일을 냅니다.

패키지 미리보기는 이미 있는 이미지를 재사용하고 없는 항목에만 썸네일 크기의 빠른 미리보기를 생성합니다.

최종 내보내기는 원본 메타데이터에서 레이아웃을 계산해 배치마다 필요한 픽셀만 현상하고 서로 다른 원본을 2~4개씩 준비해 페이지를 기록할 때까지 Core Image 그래프를 버리지 않습니다. 공유 렌더 컨텍스트와 페이지당 512MiB의 원본 래스터 예산이 레이아웃과 출력 규약을 지키면서 메모리 사용량을 제한합니다.

### 프린터 출력 프로파일

프린터 출력 프로파일은 설정(macOS는 색 관리, Windows는 내보내기)에서만 받습니다. Raw와 DNG 외의 페이지 구성과 출력에서 negaflow는 시트 합성을 먼저 마친 뒤 완성된 페이지에 고른 ICC를 한 번 반영하며, 사진 패키지나 사용자 패키지의 모든 배치에 한 사진을 반복하든 여러 사진을 섞든 똑같이 작동합니다.

이 ICC는 현상 화면의 소프트 프루프와 `PRINT` 타깃 출력에도 적용되고, 라이브러리 썸네일과 `MAIN` 타깃은 작업 색 공간을 그대로 지킵니다.

## C-print 사용

출력 프로세스는 표준과 C-print 중에서 고릅니다. C-print는 출력할 랩과 용지를 기록하고, 그 랩이 제공한 RGB ICC 프로파일로 화면 소프트 프루프를 만듭니다. 마감 질감 컨트롤은 모든 출력 프로세스와 레이아웃에서 레이아웃 아래에 자리하며, 소프트 프루프는 사용자가 지정한 측정 프로파일이 있을 때만 켜집니다.

1. 프린트 작업 공간을 열고 출력 프로세스에서 **C-print**를 선택합니다.
2. 랩과 용지를 입력하고 필요하면 레이아웃에서 마감 질감을 고르세요.
3. 그 랩과 용지, 장비용으로 받은 RGB ICC 프로파일을 불러옵니다.
4. 미리보기를 켭니다. 용지와 검정 잉크 시뮬레이션, 색역 경고는 고급 메뉴에 들어 있습니다.

유효한 RGB ICC 프로파일을 고르기 전에는 랩과 용지 설정만 먼저 저장되며, 이 RGB 미리보기 경로는 RGB 출력 프로파일만 받습니다.

## 색 규약

C-print 프루프 ICC는 화면 미리보기만 바꾸는 프루프 전용입니다. 내보내기는 프린터 출력 프로파일을 따로 고른 경우를 제외하면 설정(macOS는 색 관리, Windows는 내보내기이며 프린트 > 출력 > C-print > 고급에 읽기 전용으로 표시)에서 고른 전달 색 공간을 그대로 따릅니다.

한편 `PRINT` 현상 타깃은 별도의 출력 경로로서 유효한 RGB 프린터급 ICC 프로파일을 받아 출력을 변환합니다.

## 정확도의 한계

미리보기에는 ICC 변환이 들어 있어 종이 흰색과 블랙 포인트, 색역 밖 색을 선택적으로 시뮬레이션할 수 있습니다. 결과의 정확도는 보정된 디스플레이와 그 랩 공정의 최신 프로파일에 달려 있고 감상 조명, 약품 변화, 장비 보정, 용지 로트 차이는 실제 프린트 환경에 좌우됩니다. negaflow는 사용자가 직접 준비한 랩 프로파일만 읽습니다.
