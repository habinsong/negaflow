# 인화 레이아웃과 C-print 미리보기

[문서 홈](../README.md)

인화 화면에서는 단일 이미지, 콘택트 시트, 사진 패키지, 사용자 패키지, 시아노타입,
유리건판, 젤라틴을 구성하고 현재 레이아웃을 인화 파일로 내보낼 수 있습니다.

## 콘택트 시트

새 콘택트 시트의 기본값은 검정, 6열 × 7행, 가로·세로 간격 2 mm입니다. 나머지 레이아웃의
시트 색상 기본값은 흰색입니다. 모든 레이아웃은 시트 색상을 각각 검정·회색·흰색으로 바꿀 수
있으며 캡션, 사용자 문구, 재단 표시, 페이지 외곽선은 배경과 대비되는 색으로 자동 전환됩니다.

여백, 행·열 수, 가로·세로 간격은 하나의 실제 치수 계산을 사용합니다. 용지에 들어갈 수 없는
조합은 프리뷰를 깨뜨리지 않고 가능한 최대 간격으로 제한됩니다. 자동 용지 방향은 첫 사진이
아니라 설정한 격자를 기준으로 정합니다. **전체 맞춤**은 사진 전체를 보존하므로 셀 안에 빈
공간이 남을 수 있고, **셀 채우기**는 사진을 같은 셀 크기로 잘라 눈에 보이는 간격을 일정하게
만듭니다.

캡션은 파일명, 원래 프레임 번호, 현재 이미지 순서를 1부터 다시 매긴 순서 번호, 평점,
사용자 입력을 지원합니다. 캡션을 켜면 Mac에 설치된 글꼴을 고를 수 있으며, 같은 글꼴이
화면 미리보기와 인화 내보내기에 적용됩니다. 사진별 캡션은 왼쪽·가운데·오른쪽 정렬을
선택할 수 있습니다.
사용자 입력은 문구 상자를 여러 개 추가할 수 있고, 각 문구의 내용·정렬·위치·너비·높이를
시트 어디에나 따로 지정할 수 있습니다.

## 용지 설정과 눈금자

모든 레이아웃은 같은 용지 설정을 사용합니다. 용지 목록에는 3.5 × 5부터 24 × 36까지의
사진용 인치 규격, Letter, Tabloid, A3+, ISO A1–A6, ISO B1–B6가 있습니다. 표면은 시트
색상 바로 아래에 있으며 무광·유광·러스터·실크를 지원하고 기본값은 무광입니다.

눈금자는 기본적으로 꺼져 있습니다. 켜면 끔/켬 바로 아래에 in/cm 선택이 나타나며 용지 위쪽과
왼쪽에 가로·세로 눈금자가 표시됩니다. 1 in 또는 1 cm마다 작은 숫자를 표시하고 그 사이에는
더 짧은 보조 눈금을 둡니다.

## 한 장씩 보는 역사 인화 레이아웃

단일 이미지, 시아노타입, 유리건판, 젤라틴은 선택한 사진마다 인화 페이지를 한 장씩 만듭니다.
여러 사진을 고르면 하나의 시트에 억지로 합치지 않고 페이지를 세로로 이어 보여 줍니다.
시아노타입은 명도를 청색 단색 관계로 바꾸고, 유리건판은 흑백 네거티브, 젤라틴은 중성 흑백
포지티브로 표시합니다.

세 레이아웃은 단일 이미지와 같은 용지, 방향, 여백, 출력 설정과 인스펙터를 사용하며 내보내기와
빠른 내보내기 파일에도 같은 표현을 렌더링합니다. 특정 시대의 약품, 건판, 인화지, 관람 조건을
실측해 복원한 장치 정확도 시뮬레이션은 아닙니다.

## 인화 내보내기

빠른 내보내기 바로 아래의 **인화 내보내기**는 현재 용지 크기, 방향, 여백, 레이아웃,
검정·회색·흰색 시트, 캡션, 사용자 문구, 재단 표시를 그대로 렌더링합니다. 파일 형식, DPI, 폴더,
파일명, 전달 색공간은 내보내기 화면의 설정을 사용합니다. 색역 경고, 소프트 프루프 시뮬레이션,
인화지 표면 광택처럼 화면 확인용인 요소는 파일에 굽지 않습니다.

인화 내보내기나 빠른 내보내기가 진행되는 동안 내보내기 패널에는 불확정 원형 표시 대신 완료
페이지 수, 선형 진행 막대, 퍼센트가 표시됩니다.

### 출력 장수와 렌더링

출력 장수는 완성 페이지를 기준으로 표시합니다. 39장 6 × 7 콘택트 시트는 합성된 한 페이지,
4장 사진 패키지는 10페이지, 기본 사용자 패키지는 한 페이지, 한 장씩 보는 네 레이아웃은
빠른 내보내기와 같은 제한된 배치 스케줄러로 39파일을 만듭니다.

패키지 미리보기는 사진마다 인터랙티브·정착 풀해상도 프리뷰를 만들지 않습니다. 이미 있는
이미지를 재사용하고 없는 항목만 썸네일 크기의 빠른 프리뷰로 채웁니다. 최종 출력은 원본
메타데이터로 배치를 계산하고 각 칸에 필요한 픽셀만 현상하며, 페이지에서 쓰는 고유 원본을
한 번에 2~4개씩 준비합니다. 공유 Core Image 렌더 컨텍스트, 최종 페이지까지 이어진 그래프,
페이지당 512 MiB 원본 래스터 한도로 화면 배치와 출력 규칙을 바꾸지 않고 메모리를 제한합니다.

### 프린터 출력 프로파일

인화 화면에서 고른 프린터 출력 프로파일은 실제 인화 내보내기 결과에 적용됩니다. 먼저 한
페이지를 모두 구성한 다음, 완성된 페이지에 프로파일을 한 번 적용합니다. 같은 원본을 여러 칸에
반복한 사진 패키지와 여러 사진을 섞은 사용자 패키지 모두 각 칸이 빠지지 않습니다.

이 프로파일은 라이브러리나 현상 화면에는 적용하지 않습니다. 프로파일을 바꿨을 때 달라지는
범위는 인화 미리보기와 인화 내보내기뿐입니다.

## C-print 사용 방법

출력 방식은 일반 출력과 C-print로 나뉩니다. C-print는 인화소와 인화지를 기록하고 인화소가
제공한 RGB ICC 프로파일로 화면 소프트 프루프를 만듭니다. 공통 표면 설정은 출력 방식과
레이아웃에 관계없이 레이아웃 탭에 있습니다. 측정된 프로파일이 없을 때 임의의 “C-print 색감”을
적용하지 않습니다.

1. 인화 화면의 출력 방식에서 **C-print**를 고릅니다.
2. 인화소와 인화지를 입력합니다. 필요하면 레이아웃 탭에서 표면을 고릅니다.
3. 해당 인화소·인화지·장비용으로 제공된 RGB ICC 프로파일을 선택합니다.
4. 인화 미리보기를 켭니다. 용지와 검정 시뮬레이션, 색역 경고는 고급에 있습니다.

유효한 RGB ICC 프로파일이 없어도 인화 목적지 설정은 저장되지만 인화 미리보기는 켤 수
없습니다. 이 RGB 미리보기 경로에서는 CMYK와 device-link 프로파일을 받지 않습니다.

## 색상 처리 원칙

C-print 프루프 ICC는 화면 확인 전용입니다. 내보내는 파일의 픽셀이나 임베디드 프로파일에는
적용하지 않습니다. 별도의 프린터 출력 프로파일을 고르지 않았다면 인화 내보내기는 내보내기
설정에 표시된 전달 색공간을 사용합니다. 인화소가 소프트 프루프용으로 배포한 프로파일이 전달
프로파일로 몰래 적용되는 일을 막기 위한 구분입니다.

기존 `PRINT` 현상 target은 별도 기능으로 남습니다. 이 경로는 유효한 RGB printer-class ICC가
필요하며 그 프로파일을 거쳐 출력합니다.

## 정확도 한계

미리보기에는 ICC 변환이 적용되며 용지 흰색, 검정점, 색역 밖 색상을 선택적으로 확인할 수
있습니다. 정확도는 보정된 모니터와 현재 인화 공정에 맞는 프로파일에 달려 있습니다. 관람 조명,
약품 변화, 장비 보정 상태, 인화지 로트 차이는 예측하지 못합니다. negaflow는 인화소 프로파일을
내장하거나 임의로 만들지 않습니다.
