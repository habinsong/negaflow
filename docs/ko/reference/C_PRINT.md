# 인화 레이아웃과 C-print 미리보기

[문서 홈](../README.md)

인화에는 레이아웃이 여덟 가지 있습니다. 단일 이미지, 콘택트 시트, 사진 패키지, 사용자 패키지, 시아노타입, 유리 건판, 젤라틴 실버, 워터마크입니다.

## 콘택트 시트

- 새 콘택트 시트는 검은 시트에 6열 × 7행, 간격 2mm로 시작합니다. 다른 레이아웃은 모두 흰 시트로 시작합니다. 레이아웃마다 시트를 검정, 회색, 흰색으로 바꿀 수 있고 캡션, 사용자 텍스트, 재단선, 페이지 윤곽선은 대비되는 색으로 저절로 바뀝니다.
- 여백, 행·열 수, 간격은 하나의 물리 레이아웃 규약을 따릅니다. 불가능한 조합은 미리보기가 깨지지 않도록 가능한 가장 큰 간격으로 줄입니다. 자동 방향은 격자를 따릅니다. **맞춤**은 사진 전체를 보이게 하며 셀 안에 빈 곳이 남을 수 있습니다. **셀 채우기**는 사진을 공통 셀에 맞춰 자르고 여백을 고르게 합니다.
- 캡션은 파일 이름, 원본 프레임 번호, 현재 이미지 순서에서 1부터 세는 순번, 평점, 사용자 텍스트 중에서 고릅니다. 설치된 Mac 글꼴을 고를 수 있고 미리보기와 내보내기가 같은 글꼴을 씁니다. 이미지별 캡션은 왼쪽, 가운데, 오른쪽으로 맞춥니다. 사용자 텍스트는 독립된 상자 여러 개를 지원하고 상자마다 텍스트, 정렬, 위치, 너비, 높이를 따로 갖습니다.

## 용지 설정과 눈금자

모든 레이아웃이 같은 용지 설정을 씁니다. 용지 목록에는 3.5 × 5에서 24 × 36까지 흔한 사진 인치 규격, Letter, Tabloid, A3+, ISO A1–A6, ISO B1–B6이 있습니다. 표면은 시트 색 바로 아래에 있고 무광(기본값), 유광, 러스터, 실크가 있습니다.

눈금자는 기본값이 꺼짐입니다. 켜면 스위치 아래에 인치/cm 선택기가 생기고 페이지 위에 가로 눈금자, 왼쪽에 세로 눈금자가 붙습니다. 정수 인치나 센티미터에 숫자가 붙고 그 사이에 작은 눈금이 있습니다.

## 단일 레이아웃과 고전 레이아웃

단일 이미지, 시아노타입, 유리 건판, 젤라틴 실버는 선택한 사진마다 한 페이지를 만듭니다. 사진을 여러 장 고르면 세로로 쌓아 보여 줍니다. 시아노타입은 휘도를 파란 단색 이미지로, 유리 건판은 단색 네거티브로, 젤라틴 실버는 중성 단색 포지티브로 보여 줍니다.

이 세 스타일은 단일 이미지와 같은 용지, 방향, 여백, 출력, 인스펙터 설정을 쓰며 내보내기와 빠른 내보내기에도 그대로 렌더링됩니다. 의도한 시각 스타일이지 특정 옛 약품, 건판, 인화지, 감상 조건을 측정해 재현한 것이 아닙니다.

## 워터마크와 레이아웃 템플릿

워터마크는 레이아웃 종류 메뉴의 독립된 항목입니다. 고르면 용지 크기가 사진 비율로 바뀌고(이후 다른 크기를 고를 수 있음) 사진 바깥에 테두리가 생깁니다. 이름 위치 메뉴는 항상 쓸 수 있고 아래 가운데, 왼쪽 위, 가운데 위, 오른쪽 위가 있으며, 위쪽 위치를 고르면 위쪽 테두리가 켜집니다. 셔터 속도에는 따옴표를 덧붙이지 않고, 비어 있는 텍스트 칸은 비어 있는 채로 둡니다. 이름 텍스트는 위치 안에서 가운데 정렬입니다. 이름과 히스토그램이 같은 위치에 있으면 히스토그램이 이름 위에 놓이고 각각 가운데 정렬됩니다.

레이아웃 템플릿은 레이아웃, 용지 설정, 시트 색, 워터마크 설정을 복원한 뒤 미리보기를 새로 고칩니다. DPI와 눈금자 설정은 그대로입니다. 이 항목이 생기기 전에 저장한 템플릿은 현재의 시트 색과 워터마크를 유지합니다. 항목 배치와 DNG 원본·색 공간 규칙은 [라이브러리에서 인화까지](../product/WORKFLOW.md)에 있습니다.

## 인화 내보내기

빠른 내보내기 바로 아래의 **인화 내보내기**는 현재 페이지 크기, 방향, 여백, 레이아웃, 시트 색, 캡션, 사용자 텍스트, 재단선을 렌더링하고, 내보내기 패널에 보이는 형식, DPI, 폴더, 이름 규칙, 전달 색 공간을 씁니다. 색역 경고, 소프트 프루프 시뮬레이션, 용지 표면 광택처럼 화면에서만 쓰는 보조 표시는 파일에 굽지 않습니다. 인화 내보내기가 어느 경로로든 돌아가는 동안 내보내기 패널에는 빙글빙글 도는 표시 대신 완료한 페이지 수, 막대 진행률, 백분율이 나옵니다.

### 페이지 수와 렌더링

출력 수는 완성된 페이지 수입니다. 사진 39장의 6 × 7 콘택트 시트는 합성한 페이지 한 장, 4장짜리 사진 패키지는 10페이지, 기본 사용자 패키지는 한 페이지로 내보내고, 단일 이미지 계열 레이아웃은 빠른 내보내기와 같은 제한된 배치 스케줄러로 39개 파일을 냅니다.

패키지 미리보기는 사진마다 인터랙션용과 안정화된 전체 해상도 미리보기를 만들지 않습니다. 있는 이미지를 재사용하고 없는 항목에만 썸네일 크기의 빠른 미리보기를 만듭니다. 최종 내보내기는 원본 메타데이터에서 레이아웃을 구하고 배치마다 필요한 픽셀만 현상하며 서로 다른 원본을 2~4개씩 준비하고 페이지를 쓸 때까지 Core Image 그래프를 이어 둡니다. 공유 렌더 컨텍스트와 페이지당 512MiB의 원본 래스터 예산이 보이는 레이아웃과 출력 규약을 바꾸지 않고 메모리를 제한합니다.

### 프린터 출력 프로파일

인화 작업 공간에서 고른 프린터 출력 프로파일은 내보낸 결과의 일부입니다. negaflow는 페이지 전체를 먼저 구성한 뒤 완성된 페이지에 프로파일을 한 번 적용합니다. 사진 패키지나 사용자 패키지의 모든 배치가 대상이며, 한 사진을 반복하는 구성이든 여러 사진을 섞는 구성이든 같습니다. 이 프로파일은 라이브러리나 현상 미리보기에는 영향을 주지 않고 인화 미리보기와 인화 내보내기에만 영향을 줍니다.

## C-print 사용

출력 프로세스는 표준과 C-print 중에서 고릅니다. C-print는 목적지 랩과 용지를 기록하고, 그 랩이 제공한 RGB ICC 프로파일로 화면 소프트 프루프를 만듭니다. 표면 컨트롤은 모든 출력 프로세스와 레이아웃에서 레이아웃 아래에 있습니다. 측정된 프로파일이 없으면 일반적인 'C-print 룩'을 적용하지 않습니다.

1. 인화 작업 공간을 열고 출력 프로세스에서 **C-print**를 고릅니다.
2. 랩과 용지를 입력합니다. 필요하면 레이아웃에서 표면을 고릅니다.
3. 그 랩, 용지, 장비용으로 받은 RGB ICC 프로파일을 고릅니다.
4. 인화 미리보기를 켭니다. 용지와 검정 잉크 시뮬레이션, 색역 경고는 고급에 있습니다.

유효한 RGB ICC 프로파일이 없으면 목적지 설정은 저장되지만 인화 미리보기는 쓸 수 없습니다. CMYK와 디바이스 링크 프로파일은 이 RGB 미리보기 경로에서 받지 않습니다.

## 색 규약

C-print 프루프 ICC는 프루프 전용입니다. 화면 미리보기만 바꾸고 내보낸 파일의 픽셀이나 내장 프로파일은 바꾸지 않습니다. 인화 내보내기는 프린터 출력 프로파일을 따로 고르지 않는 한 내보내기 설정에서 고른 전달 색 공간을 씁니다. 그래서 랩의 소프트 프루프 프로파일이 전달 프로파일로 조용히 쓰이는 일이 없습니다. `PRINT` 현상 타깃은 별개입니다. 유효한 RGB 프린터급 ICC 프로파일이 필요하고 그 프로파일로 출력을 변환합니다.

## 정확도의 한계

미리보기에는 ICC 변환이 들어 있고 종이 흰색, 블랙 포인트, 색역 밖 색을 선택적으로 흉내 낼 수 있습니다. 정확도는 보정된 디스플레이와 해당 랩 공정의 최신 프로파일에 달려 있습니다. 감상 조명, 약품 변화, 장비 보정, 용지 로트 차이는 예측하지 못합니다. negaflow는 랩 프로파일을 번들하거나 만들어 내지 않습니다.
