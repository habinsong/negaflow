# GrainMend IR이 피해야 할 필름

[문서 홈](../README.md)

적외선 청소는 가시광 이미지와 적외선 이미지를 따로 읽어 겹쳐서 결함을 찾지만, 필름의 발색 물질에 따라 동작 여부가 달라집니다.

- 일반 컬러 필름과 염료 기반 흑백 필름은 IR과 호환됩니다.
- 일반 흑백 필름은 은이 남아 IR을 막으므로 결함 지도가 어긋납니다.
- 코다크롬은 다른 컬러 필름과 IR 감쇠가 달라 보정이 모자라거나 과해지기 쉽습니다.

근거:

- [Epson technical notes and limits](https://files.support.epson.com/pdf/pr48pr/pr48prps.pdf)
- [Epson film type table](https://files.support.epson.com/htmldocs/pr449p/pr449pug/projs_3.htm)
- [SilverFast on black and white and Kodachrome](https://www.silverfast.com/showdocu/en.html?direct=1&docu=1300)

> [!CAUTION]
> 필름 재질이 확인된 경우에만 IR을 자동으로 켜며, 잘못된 IR 마스크는 실제 화면 구조를 결함으로 오인해 지워 버립니다.

## 자동으로 적용되는 곳

구분 근거는 상을 이루는 물질입니다. 컬러 필름은 현상 뒤 염료만 남고 염료는 적외선을 통과시키는 반면, 흑백 필름은 은으로 된 상이 적외선을 차단하므로 보정이 사진 자체를 통째로 결함 영역으로 읽어 지워 버립니다.

| 필름 종류 | 자동 IR | 이유 |
|---|---|---|
| 컬러 네거티브 | 조건부 | 염료 상. 플러그인이 IR을 보고하고 결함별 가시광 빨강 채널 확인(`>= 4σ`)과 면적 한도(`<= 5%`)를 통과해야 함 |
| 컬러 포지티브 | 조건부 | 염료 상. 컬러 네거티브와 똑같은 조건 |
| 흑백 네거티브와 포지티브 | 꺼짐 | 은 상이 적외선을 막음 |

`FilmType`만으로는 염료 기반 흑백과 은 흑백, 혹은 코다크롬과 일반 슬라이드를 구별할 수 없어서 두 경우는 사용자가 직접 선택합니다.

- 염료 기반 흑백은 흑백 모드로 스캔하므로 필름 자체는 적외선을 통과시키더라도 기본 상태에서 IR을 꺼 둔 채 사용자 선택에만 맡깁니다.
- 코다크롬은 컬러 슬라이드라 IR을 제안하지만 염료의 적외선 감쇠가 E-6과 달라 결함이 덜 지워지거나 과하게 지워질 수 있으니 결과가 어색하면 레이어를 끄세요.

## 정렬 검사

`InfraredDefectRemoval`은 먼저 IR 결함 점을 RGB 빨강 채널의 주변 어두운 영역과 대조해 보고, 결함 단서가 적을 때만 고역 통과 IR 누설 질감과 빨강 채널의 상관을 비교해 정수 오프셋을 찾습니다. 전역 결과에는 `AlignmentDiagnostics`가 붙으며, 각 결함의 최종 오프셋을 빨강 채널 주변에서 다시 정밀하게 구하기 위한 출발점으로만 활용합니다.

| 상태 | 뜻 |
|---|---|
| `notRequested` | 호출한 쪽이 두 평면이 이미 정렬되었다고 알림 |
| `aligned` | 상관이 문턱을 넘고 최적점이 탐색 범위 안에 있음 |
| `insufficientTexture` | IR에 정렬 단서가 너무 적음 |
| `weakCorrelation` | 상관이 문턱에 못 미침 |
| `searchLimitReached` | 최적점이 탐색 경계에 있음 |

전역 출발점이 뒤의 세 상태로 분류되더라도 검출은 계속 진행되어, `(0,0)`에서 시작해 선명한 IR 후보들로부터 대략적인 합의 오프셋을 투표로 찾습니다. 그 뒤 후보마다 가시광 빨강 채널의 주변 대조(`>= 4σ`)와 최대 면적 비율(`5%` 기본값)을 통과할 때만 보정을 반영하고, 문턱을 넘지 못하면 `noDefects`나 `coverageTooHigh` 상태로 멈춥니다.

자동 테스트는 실제 장치와 필름별 RGB/IR 정렬 확인을 대신할 수 없으므로 실제 필름을 스캔해 직접 확인해야 합니다.

SANE 장치 제어와 캡처 코드는 별도 저장소 `negaflow-scanner-sane`에만 들어 있습니다.
