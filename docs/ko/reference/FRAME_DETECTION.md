# 평판 프레임 자동 검출이 필름을 찾는 방법

[문서 홈](../README.md)

평판 프리뷰에는 홀더와 그 사이로 빠져나온 빛, 그리고 꽂혀 있는 필름이 함께 담깁니다. 자동 프레임
검출은 본 스캔을 시작할 가치가 있으려면 그 그림에서 어디가 필름인지, 컷이 어디서 끝나고 다음 컷이
어디서 시작하는지를 먼저 정해야 합니다.

검출기는 프리뷰가 담은 실제 영역이 몇 mm인지 알고 있으므로, 비율로 짐작하지 않고 규격을 픽셀로
정확히 옮깁니다.

## 필름은 밝기가 아니라 질감으로 찾습니다

밝기로는 필름과 빈 홀더 창을 구분할 수 없습니다. Epson GT-X900 프리뷰 실측입니다.

| 그 열에 있는 것 | 평균 밝기 |
|---|---|
| 빈 홀더 창, 광원이 그대로 통과 | 0.92 |
| 옆 창에 꽂힌 필름 | 0.10 |
| 홀더 마스크 | 0.002 |
| 바탕이 흰색인 사제 홀더 | 1.00 |

밝기로 고르면 빈 창을 집고 필름을 버리게 되며, 바탕이 흰 홀더에서는 순서가 통째로 뒤집힙니다.

질감에는 그런 모호함이 없습니다. 그레인과 그림은 필름에만 있기 때문입니다.

| 그 열에 있는 것 | 세로 방향 디테일 |
|---|---|
| 필름 | 0.0044 ~ 0.032 |
| 홀더 마스크, 빈 창, 흰 바탕 | 0.00005 ~ 0.001 |

한 자릿수 이상 벌어지고, 필름 종류·홀더·극성이 무엇이든 부호가 뒤집히지 않습니다. 아래 모든
단계가 이 성질 위에 서 있습니다.

## 단계

1. **열 질감.** 프리뷰의 열마다 디테일을 잽니다. 그레인과 그림이 있는 열이 슬롯 후보가 됩니다.
2. **슬롯.** 후보 열을 필름 가장자리까지 넓힌 뒤 선택한 규격의 폭과 대조합니다. 스캔 영역 끝에
   걸린 슬롯은 버립니다. 스캔 영역이 반으로 자른 창이라, 본 스캔이 엉뚱한 영역을 찍습니다.
3. **구획.** 슬롯 안에서 필름이 놓인 행을 위아래 홀더와 가릅니다. 옆의 홀더와 다르거나 **또는**
   질감이 있으면 필름으로 봅니다. 밝기만 보면 슬라이드의 밀도 높은 컷을 잃고, 질감만 보면 여백과
   평평한 컷을 잃습니다.
4. **격자.** 여백 위치의 빗살을 (피치, 위상) 평면 전체에서 맞춥니다. 점수는 컷 안과 여백의 대비라,
   여백이 맑은 베이스든 최대 밀도든 그것을 덮은 홀더 리브든 판정이 달라지지 않습니다.
5. **보정.** 경계마다 가장 가까운 여백에 붙인 뒤, 전체를 다시 등간격으로 맞춥니다. 스트립의 컷은
   등간격이기 때문입니다. 같은 스트립을 두 번 스캔해도 0.2mm 안에서 같은 자리에 섭니다.

## 내놓지 않는 경우

| 상황 | 결과 |
|---|---|
| 필름이 없는 홀더 | 아무것도 없음. 창에 질감이 없어 슬롯이 서지 않습니다 |
| 세 창 중 한 곳에만 스트립을 꽂은 홀더 | 꽂힌 창만 |
| 스캔 영역에 반이 잘린 창 | 버림 |
| 필름 끝을 벗어난 컷 | 버림. 가운데 컷은 미노광이어도 남깁니다 |
| 주기적인 여백 증거가 없는 스트립 | 임의의 격자를 세우지 않고 아무것도 내지 않음 |

## 규격

스트립을 따라가는 길이가 프레임 피치 방향이고, 스트립 폭 방향 길이가 슬롯 폭입니다. 둘 다 선택한
규격에서 나오므로 하프프레임과 645도 두 축이 뒤바뀌지 않습니다.

| 규격 | 스트립 진행 | 스트립 폭 |
|---|---|---|
| 35mm 풀프레임 | 36mm | 24mm |
| 35mm 정방형 | 24mm | 24mm |
| 35mm 하프프레임 | 18mm | 24mm |
| 120 · 6×4.5 | 41.5mm | 56mm |
| 120 · 6×6 ~ 6×17 | 56 ~ 168mm | 55 ~ 56mm |

35mm 피치는 퍼포레이션 이송이 정해 거의 흔들리지 않으므로 좁게 찾고, 120은 카메라가 간격을
정하므로 넓게 엽니다. 어느 쪽도 특정 숫자로 못 박지 않습니다.

## 무엇을 측정했나

Epson GT-X900 실제 프리뷰 10장. 149.86 × 246.38mm 영역을 300dpi로 담은 1768 × 2906 이미지입니다.

| 프리뷰 | 홀더 | 결과 |
|---|---|---|
| 흑백 네거티브, 세 스트립 | 정품 | 슬롯 3개 × 6컷 |
| 흑백 네거티브, 한 스트립만 | 정품 | 슬롯 1개 × 6컷, 빈 창 두 개는 무시 |
| 컬러 네거티브, 세 스트립 | 정품 | 슬롯 3개 × 6컷 |
| 컬러 네거티브, 한 스트립만 | 정품 | 슬롯 1개 × 6컷 |
| 컬러 슬라이드, 세 스트립 | 정품 | 슬롯 3개 × 6컷 |
| 컬러 슬라이드, 한 스트립만 | 정품 | 슬롯 1개 × 6컷 |
| 컬러 네거티브, 여백을 홀더가 가림 | 사제 | 슬롯 1개 × 5컷 |
| 컬러 네거티브, 홀더가 스캔 영역보다 넓음 | 사제 | 온전한 창 2개, 반 잘린 창 2개는 버림 |

모든 스트립의 적합 피치는 37.65 ~ 38.12mm입니다. 검출은 디버그 빌드에서 프리뷰 한 장당
0.5 ~ 0.9초 걸립니다.

> [!NOTE]
> 위 측정은 35mm뿐입니다. 120 규격은 합성 픽스처로만 확인했으므로, 실제 120 프리뷰에서 간격
> 탐색을 아직 검증하지 않았습니다.

## 코드 위치

| 파일 | 역할 |
|---|---|
| `FlatbedFrameGridDetector.swift` | 진입점, 규격 기하, 프레임 범위 |
| `FlatbedFrameGridDetector+Profiles.swift` | 열·행 프로파일, 질감, 공통 통계 |
| `FlatbedFrameGridDetector+Slots.swift` | 슬롯, 필름 유무, 구획 |
| `FlatbedFrameGridDetector+Grid.swift` | 여백 증거, 빗살 적합, 경계 보정 |

물리 크기를 모르는 프리뷰에는 `FlatbedFrameDetector`가 폴백으로 남아 있습니다.
