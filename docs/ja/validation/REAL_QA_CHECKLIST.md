# 実機点検リスト

[ドキュメントホーム](../README.md)

自動テストとビルドでは確認できない項目です。最終的な画面の確認と実機の確認はユーザーが担当
します。当てはまる必須項目に結果と根拠がそろって初めて、リリース候補を承認できます。

結果は`PASS`、`FAIL`、`BLOCKED`、`N/A`のどれかで書きます。`FAIL`、`BLOCKED`、`N/A`には理由が
要ります。

> [!IMPORTANT]
> この表を埋めていないビルドに、実機・最終画質・署名・公証の確認が済んだとは書きません。自動
> テストの合格は、この点検の代わりになりません。

## 2. 取り込み、現像、書き出し

JPEG、TIFF、今のデコーダーが読むDNG/RAW、高解像度ファイルを最低1つずつ使います。実行の前後で
原本のSHA-256を記録します。

| 結果 | 確認すること | 根拠または問題 |
|---|---|---|
|  | 取り込みの前後で原本のバイト列が同じ。 |  |
|  | 重複取り込みの警告と選択肢が分かりやすい。 |  |
|  | 最初の状態が手動補正と`main`ターゲット。 |  |
|  | 切り抜き、向き、トーン、色、ディテール、部分補正、取り消しが想定どおり動く。 |  |
|  | 原本と現像結果の比較、クリップ表示が書き出しと合う。 |  |
|  | JPEGと16-bit TIFFが開き、メタデータが正しい。 |  |
|  | 名前の衝突、取り消し、失敗、再開で、一部のファイルだけ成功として残らない。 |  |
|  | 必要な編集履歴やキャッシュがないときは、原本を書き出さずエラーにする。 |  |

## 5. 外部プラグインと実機スキャナー

SANEの実装は、別配布の`negaflow-scanner-sane`からインストールして設定します。プラグインと装置の
根拠は、そのリポジトリとこの記録の両方に残します。

| 結果 | 確認すること | 根拠または問題 |
|---|---|---|
|  | 初めて見るプラグインはユーザーが承認する必要がある。 |  |
|  | プラグインを消す・入れ替えると以前の承認が無効になる。 |  |
|  | 装置探しに、プラグインが報告した実機だけが出る。 |  |
|  | 解像度、ビット深度、モード、領域、プレビュー、露光、IRは報告された機能だけ出る。 |  |
|  | 対応しない機能は隠すか、正確な無効理由を出す。 |  |
|  | プレビュー、本スキャン、取り消し、時間切れ、接続解除、プラグイン終了が安全に終わる。 |  |
|  | 結果の大きさ、ビット深度、領域、適用設定が報告値と合う。 |  |
|  | CLIの`detect --json`と`capabilities <id> --json`がアプリの画面と合う。 |  |
|  | プラグインのファイル、依存、設定、ログが本体アプリとこのリポジトリの外にある。 |  |

## 6. GrainMendと画質

カラーネガ、対応する色素式白黒、一般的な銀塩白黒、スライド、きれいなフレーム、ホコリ、キズ、
グレイン、顔、空、細かい模様をひととおり確認します。

| 結果 | 確認すること | 根拠または問題 |
|---|---|---|
|  | GrainMendを他社のハードウェアIRクリーニングと同じだとは書かない。 |  |
|  | 対象の欠陥を減らしつつ、質感と輪郭を壊しすぎない。 |  |
|  | きれいなフレームでの誤検出が受け入れられる範囲。 |  |
|  | RGBとIRが合い、ずれたフィルムや対応外のフィルムははっきり失敗する。 |  |
|  | IRがフィルム種別の限界を守り、元の資料を保つ。 |  |
|  | 前後の100%クロップとマスクを、設定値とアプリのバージョンと一緒に残す。 |  |

## 8. アップグレードとリリース

| 結果 | 確認すること | 根拠または問題 |
|---|---|---|
|  | アップグレード後も既存のカタログとサイドカーが残る。 |  |
|  | 対応しない古いバージョン・スキーマは安全に失敗し、復旧方法を示す。 |  |
|  | リリース一式にアプリ、dSYM、チェックサム、ライセンス、必要な一覧がある。 |  |
|  | テスト資料、原本、認証情報、プラグイン実装が一式に入っていない。 |  |
|  | 既知の問題と装置・プロファイルの根拠がリリースノートと合う。 |  |

リリース判定: `APPROVE`、`REJECT`、`BLOCKED`

次のどれかが再現したら、直して確認し直すまで自動的に`REJECT`です。

- 原本を変える

- 署名や公証の不一致
- 資料の消失
