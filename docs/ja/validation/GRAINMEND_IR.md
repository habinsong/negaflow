# GrainMend IR 実スキャン測定

[ドキュメントホーム](../README.md)

GrainMend IR が欠陥を実際にどれだけ消すかを、合成フィクスチャではなく実スキャンで測った値です。

| 項目 | 値 |
|---|---|
| 素材 | Epson GT-X900、カラーネガ、2400dpi、16ビット |
| ペア | 5組（本スキャンと赤外パス） |
| 採点した欠陥 | 1フレームあたり140〜338個 |
| 測定日 | 2026-08-11 |

## 採点のしかた

検出器に自分を採点させません。写真が確認できたものだけを欠陥として数えます。赤外の候補を red
チャンネルの暗い痕にその欠陥自身の局所ずれで合わせ、その山が周囲のノイズより4シグマ上に出たとき
だけ残します。除去率は欠陥中心の対数濃度超過をリング基準線と比べ、補正の前後で測った値です。
過補正は同じ値が負になったもの、つまり中心が周囲より明るくなった場合です。

## まず取り込みから

赤外パスは本スキャンと同じガンマテーブルと焦点で撮る必要があります。装置の既定のままだとフィルム
ベースが白側で切れ（フレームの9.07%が65535に固定）、欠陥の深さを測る基準線そのものが失われます。
両パスを揃えればクリッピングは0です。その修正より前に測った数字は検出器について何も語りません。

## 結果

| フレーム | 候補から確認 | 倍率 | 中心の除去率 | 過補正 軽微/中程度/深刻 |
|---|---|---|---|---|
| 19 | 483 → 262 | 1.12 | 90% | 5 / 0 / 0 |
| 20 | 726 → 407 | 1.84 | 85% | 16 / 8 / 3 |
| 21 | 1138 → 494 | 1.52 | 96% | 24 / 5 / 0 |
| 22 | 969 → 674 | 1.26 | 93% | 25 / 3 / 3 |
| 23 | 540 → 341 | 1.32 | 95% | 13 / 2 / 0 |

倍率は可視光濃度を赤外濃度で割った実測値です。遮蔽は波長に対してほぼ平坦なので、1に近い値は両
パスが「何が覆われていたか」について同じ答えを出していることを意味します。軽微は中心が周囲より
1〜3%明るくなった場合でフィルム粒子より小さく、深刻は6%を超えた場合です。検出に1フレーム
0.6〜0.9秒、補正の適用にさらに0.1〜0.3秒かかります。

補正量の96〜99%が実際の赤外欠陥から8ピクセル以内にあり、red 十分位ごとの平均補正量に傾向は
ありません。広げた検出が画面へ漏れていないということです。

## 欠陥の大きさ別

広いほこりだけが残り、傷はきれいに消えるという状態でした。4つの段階が数ピクセルより大きい欠陥
でだけ食い違い、5つ目がすべての欠陥を一定量だけ消し残していました。

| 短辺半径 | 前 | 後 |
|---|---|---|
| 1〜2px | 52〜74% | 77〜95% |
| 3〜4px | 77〜89% | 93〜99% |
| 5〜7px | 0〜91% | 24〜99% |
| 12〜17px | 0〜73% | 58〜89% |
| 18px以上 | 0% | 73〜93% |

- 基準線の構造要素を最初のパスで観測した欠陥の大きさから広げていましたが、その観測自体が同じ
  基準線で行うため、構造要素より広い欠陥は自分の内側を測って小さく見えます。今は解像度から
  直接決めます。
- 候補のしきい値は1ピクセルの有意性なので、薄くて広いほこりは1ピクセルも越えられませんでした。
  同じ有意水準を欠陥が覆う面積に合わせて適用します。
- 帰無分布を探索面全体から取っていたため、探索面ほど大きい欠陥は自分自身が帰無になり、測った
  倍率が半分になりました。
- 戻す量をフィルム自身の下限ではなく3シグマの判定線から測っていたため、その分がすべての欠陥に
  残りました。
- 大きいという理由で選ばれた山の上振れを固定1シグマで引いていました。その偏りは4シグマ関門の
  逆ミルズ比です。関門ではそのまま慎重に、8シグマを超えたら削りません。

## 未確認

- 補正後のフレームを目で見ていません。ここでの軽微な過補正は数値であって、見え方の判断では
  ありません。
- 18枚のバッチをアプリで通して回していません。
- フレーム20が85%と他より低いままです。赤外濃度自体が他フレームの60%程度で、入力が薄いカット
  だと思われます。
- スキャナは1台だけです。V800、V850、Coolscan は測っていません。
- 低解像度のカラー16ビットスキャンが300dpi以下で真っ黒になります。2400dpi は正常で製品への影響
  は確認されていませんが、原因は不明です。
