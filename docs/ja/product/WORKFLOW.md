# ライブラリからプリントまで

[ドキュメントホーム](../README.md)

読み込み、フォルダー現像、設定のコピー、スキャナーのサムネイル、プリント出力までの動作をまとめています。ライブラリのフォルダーは、各写真の実際の保存場所を基準にします。

> [!IMPORTANT]
> 写真を別のフォルダーへ移動する操作を除き、元ファイルは変更しません。ライブラリから外す操作と、Finderでファイルを削除する操作も別です。

## 読み込み

読み込み操作の下に進捗バー、パーセント、完了枚数と総枚数を表示します。メタデータはバックグラウンドで読み、追加するフレームをまとめて登録します。

読み込んだ写真の自動現像は**初期値ではオフ**です。元画像のサムネイルとフォルダーを先に表示し、フォルダーでプロセスとターゲットを適用するか、現像画面に入ったときに現像を始めます。常に自動現像する場合は、**設定 → ワークフロー → 読み込んだ画像を自動現像** をオンにします。

読み込みの自動現像は、その読み込みで新しく登録したフレームだけに適用し、既存の現像状態を上書きしません。現像済み写真を処理し直すのは、フォルダーの**適用**または設定の貼り付けを明示的に実行したときだけです。

スキャナー画像は例外です。スキャン時にフィルム種類、プロセス、ターゲットが決まっているため、公開後すぐに現像します。現像とプリントのフィルムストリップでは、カラーネガ、スライド、白黒ネガ、白黒ポジのすべてで現像済みサムネイルを使います。

## フォルダー

- 折りたたみ状態は保存されます。新しいフォルダーを作ったり再起動したりしても、他のフォルダーは勝手に開きません。
- すべてのフォルダー行に同じ `×` があります。ライブラリから外すだけで、Finderの元ファイルは残ります。
- 現像画面の写真一覧は、フォルダー内だけを縦スクロールします。

### 写真を別のフォルダーへ移す

写真を別のフォルダー行へドラッグすると、実ファイルとカタログの場所を同時に更新します。 読み込みフォルダー、アプリで作ったフォルダー、スキャン画像のフォルダーに同じ規則を使います。同名ファイルがある場合は `frame 2.tiff`、`frame 3.tiff` のように番号を付け、 上書きしません。IRの付随ファイルも同じトランザクションで移動します。

### Finder での変更

Finderで元画像や登録済みフォルダーを移動・改名した場合は、persistent bookmarkで既存のフレームを再接続します。登録済みフォルダー直下の新しい画像も自動で追加します。定期的な全件走査ではなく、変更通知が来た実フォルダーだけを読み直します。

## フォルダー単位の現像

フォルダー名の横でプロセスとターゲットを選び、**適用**を押します。別のオン・オフスイッチはありません。

以前に現像した写真を含め、そのフォルダーの全写真を再レンダリングします。プロセスとターゲットは新しい値になり、露出やコントラストなど他のユーザー補正は保ちます。適用の横には進捗バー、パーセント、完了枚数と総枚数が出ます。大量処理はレンダースロット数に合わせたキューで実行します。

## プリセットとコピー・ペースト

現像設定は7つの範囲を独立して選べます。

| 範囲 | 内容 |
|---|---|
| 入力ガンマ | 元画像の伝達特性の解釈 |
| ベース倍率 | フィルムベースの倍率 |
| ベース | フィルム種類と処理、ターゲット、スキャナープロファイル、ベース、チャンネル範囲補正、自動バランス・レベル・中性化 |
| トーン | 露出、コントラスト、濃度、ハイライト、シャドウ、白、黒、カーブ |
| 色 | 色温度、色かぶり、色の深さ、自然な彩度、彩度、ミキサー、グレーディング、キャリブレーション、白黒調色、フィルムエミュレーション |
| ディテール | 粒子、シャープ、ハレーション、明瞭度、周辺光量、ノイズ除去、GrainMend強度、部分補正 |
| ジオメトリ | クロップ、回転、反転、傾き補正、クロップ比率 |

全体ペーストとユーザープリセットは対象の現像設定を置き換えます。部分ペーストは選んだ範囲の実効値を置き換え、それ以外は保ちます。ルックの一部だけを移す場合は、トーン・色・質感の寄与を数値に展開してルック参照を外します。以前のルックが再び加算されるのを防ぎます。同じ設定を繰り返しペーストしても値は累積しません。パネル、メニュー、ショートカットは同じペースト範囲を使います。

ペーストとユーザープリセットは選択した写真すべてに適用します。1回のUndoまたはRedoで選択全体を戻します。Windowsは全対象を検証してから置き換えます。サムネイルと現在のプレビューは新しい設定で更新します。元ファイル、評価、元画像に結び付く欠陥編集はコピーしません。

ユーザープリセットは現像状態全体とジオメトリを保存します。古い形式にジオメトリ項目がなければ、互換性のため含むものとして読みます。名前を空欄にすると最初の空き番号で保存し、同名という理由で既存プリセットを上書きしません。

## スキャナープラグインがない場合

起動時にプラグインがなければ、ライブラリと現像の共通左サイドバーに、未インストール説明、 再検索、シミュレーターのブロックを自動表示しません。画像の読み込みはそのまま使えます。 再検索とシミュレーター機能を削除したわけではなく、スキャナー入口や設定から直接開けます。

## プリントレイアウトと出力枚数

プリントには単一画像、コンタクトシート、ピクチャーパッケージ、カスタムパッケージ、シアノタイプ、ガラス乾板、ゼラチンシルバー、ウォーターマークの8レイアウトがあります。個別画像型の5レイアウトは選んだ写真ごとに完成ページを作り、縦に並べます。ウォーターマークは独立したレイアウトで、ほかのレイアウトの操作は変わりません。

書き出しとクイック書き出しの枚数は、完成ページで数えます。 39枚を6 × 7のコンタクトシートに置けば合成済みの1ファイル、4面パッケージなら10ページ、 初期カスタムパッケージなら1ページ、個別画像型なら制限付きバッチの39ファイルです。

パッケージ表示は既存のサムネイル、現像画像、元画像プレビューを再利用し、どれもない写真だけ小さな高速プレビューを作ります。最終出力ではメタデータから先に配置を計算し、各配置に必要なピクセルだけを現像します。同時準備は2～4画像に制限し、共有Core Imageコンテキスト、 最終ページまで接続した画像グラフ、ページ当たり512 MiBのソースラスタ上限を使います。

## プリントのウォーターマーク

レイアウト種類でゼラチンシルバーの次にあるウォーターマークを選びます。写真を切り抜かずに下余白を付け、同じ高さの上余白も追加できます。写真比率の用紙は余白を含む比率に合わせます。

下の余白の左にはカメラとその下のレンズ、右にはロゴと焦点距離・絞り・シャッター・ISO、その下に日付が入ります。ロゴをオンにするとロゴが入り、ファイルを選ばなければ negaflow のロゴを使います。メーカーのロゴはアプリに入れていないので、手元の JPEG や PNG などの画像ファイルを選びます。設定とテンプレートにはファイルのパスだけを保存します。描画時にファイルを確認し、サイズと更新日時が同じならロゴのキャッシュを再利用します。ファイルが移動・削除されていればロゴだけを省き、そのことは下部の状態ドットと診断レポートに残ります。カメラ・レンズ・露出・日付の空欄はそのままにし、入力した文字だけを描画します。文字が長いときや縦位置の写真で余白が狭いときは、余白の中の項目をすべて同じ比率で小さくします。文字が写真の外にはみ出したり切れたりはしません。

余白の背景は白、黒、写真のぼかしから選びます。白なら文字は黒で 2 行目はグレーです。黒なら文字はすべて白です。ぼかしでは文字色とヒストグラムの色を黒と白から選びます。ヒストグラムは点の縦棒で描きます。ヒストグラムと名前はそれぞれ下中央、上の余白を付けたときは上の左・中央・右に置けます。名前の位置メニューは常に表示され、下中央、上左、上中央、上右を選べます。上の位置を選ぶと上余白も有効になります。名前は選んだ領域の中央に揃います。ヒストグラムと同じ位置なら、ヒストグラムを上、名前を下に置き、それぞれ中央に揃えます。ぼかしとヒストグラムは有効なフィルムストリップのサムネイルを再利用し、ない場合は写真画像を縮小して使います。テンプレートには用紙の色と、文字やロゴのパスを含むウォーターマークの設定すべてを保存します。

## プリントプロファイル

| 設定 | 画面 | プリント書き出し | 現像画面 |
|---|---|---|---|
| プリンター出力プロファイル | 出力結果を確認 | 完成したページ全体に適用 | 適用しない |
| C-printプルーフプロファイル | ラボと印画紙をソフトプルーフ | 配信用ファイルには焼き込まない | 適用しない |

出力プロファイルは、コンタクトシート、写真パッケージ、カスタムパッケージを一つのページに組んだ後で一度適用します。同じ写真の繰り返し配置や複数写真の混在でも、すべてに同じ変換が入ります。詳しくは[プリントレイアウトとC-printプレビュー](../reference/C_PRINT.md)を参照してください。

## DNG の書き出し

DNG は現像した写真を 16bit リニア RGB(`PhotometricInterpretation = LinearRaw`)の無圧縮ファイルとして書きます。色空間は書き出しで選んだ sRGB、Display P3、Adobe RGB のいずれかです。トーンと色は焼き込み済みなので、他のアプリは出力基準のファイルとして読みます。著作権、スキャナー、ソフトウェア、日付、フィルムの記録は TIFF と同じメタデータ方針で入れ、元のカメラの EXIF、IPTC、GPS は移しません。1 画素 6 バイトなので、2,400 万画素 1 枚で約 144 MB です。

DNG を選べるのは無圧縮の元ファイル（TIFF、カメラ RAW、DNG）です。JPEG、PNG、HEIC は DNG で書き出せません。現像、`PRINT` ターゲット、プリントのレイアウトも DNG に対応します。プリント DNG は合成したページを標準 RGB と ColorMatrix で記録し、プリンター ICC 変換は適用しません。DNG の書き出しは、書き出しで選択したフォルダーに `.dng` 拡張子で保存します。最終ファイルを保存して確認した後に完了とします。exiftool と Apple の画像デコーダーで読めることを確認しています。Lightroom や Camera Raw での描画は測っていません。

## 元のファイルへの影響

| 操作 | Finder の元ファイル | カタログと編集内容 |
|---|---|---|
| フォルダーの `×` | そのまま | そのフォルダーと写真をライブラリから外す |
| 写真を別のフォルダーへドラッグ | 移動する。名前が重なれば別名を付ける | 新しい場所へつなぎ直す |
| Finder での移動・名前変更 | ユーザーが変えた場所を保つ | ブックマークで自動的につなぎ直す |
| フォルダー単位の現像を適用 | そのまま | プロセスとターゲットを更新して描き直す |
| プリセット・コピー／ペースト | そのまま | 選んだ現像値と配置の値を更新 |
| プリント書き出し | そのまま | 別の出力ファイルとレンダー記録を作る |

## 2,000フレーム確認

大きなライブラリでは256枚を超えると長距離の自動スクロールを止め、表示に必要な行だけを作ります。2,000フレーム検査は24 MPから60 MP、3200 DPI、4800 DPIの資料を50フォルダーへ入れ、すべてのプロセスとターゲット、クロップ、方向を混ぜて現像と保存を確認します。

```bash
bash scripts/performance/run-virtual-library-stress.sh
```

この検査は通常の `swift test` では省略します。
