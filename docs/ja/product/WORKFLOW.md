# ライブラリからプリントまで

[ドキュメントホーム](../README.md)

読み込み、フォルダー現像、設定のコピー、スキャナーのサムネイル、プリント出力までの動作をまとめています。ライブラリのフォルダーは、各写真の実際の保存場所を基準にします。

> [!IMPORTANT]
> 写真を別のフォルダーへ移動する操作を除き、元ファイルは変更しません。ライブラリから外す操作と、Finderでファイルを削除する操作も別です。

## 読み込み

読み込み操作の下に進捗バー、パーセント、完了枚数と総枚数を表示します。メタデータはバックグラウンドで読み、追加するフレームをまとめて登録します。

読み込んだ写真の自動現像は**初期値ではオフ**です。元画像のサムネイルとフォルダーを先に表示し、フォルダーでプロセスとターゲットを適用するか、現像画面に入ったときに現像を始めます。常に自動現像する場合は、**設定 → ワークフロー → 読み込んだ画像を自動現像** をオンにします。

読み込みの自動現像は、その読み込みで新しく登録したフレームだけに適用し、既存の現像状態を上書きしません。現像済み写真を処理し直すのは、フォルダーの**適用**または設定の貼り付けを明示的に実行したときだけです。

スキャナー画像は例外です。スキャン時にフィルム種類、プロセス、ターゲットが決まっているため、公開後すぐに現像します。現像とプリントのフィルムストリップでは、カラーネガ、スライド、白黒ネガ、白黒ポジのすべてで現像済みサムネイルを使います。

## フォルダー

- 折りたたみ状態は保存されます。新しいフォルダーを作ったり再起動したりしても、他のフォルダーは勝手に開きません。
- すべてのフォルダー行に同じ `×` があります。ライブラリから外すだけで、Finderの元ファイルは残ります。
- 現像画面の写真一覧は、フォルダー内だけを縦スクロールします。

### 写真を別のフォルダーへ移す

写真を別のフォルダー行へドラッグすると、実ファイルとカタログの場所を同時に更新します。 読み込みフォルダー、アプリで作ったフォルダー、スキャン画像のフォルダーに同じ規則を使います。同名ファイルがある場合は `frame 2.tiff`、`frame 3.tiff` のように番号を付け、 上書きしません。IRの付随ファイルも同じトランザクションで移動します。

### Finder での変更

Finderで元画像や登録済みフォルダーを移動・改名した場合は、persistent bookmarkで既存のフレームを再接続します。登録済みフォルダー直下の新しい画像も自動で追加します。定期的な全件走査ではなく、変更通知が来た実フォルダーだけを読み直します。

## フォルダー単位の現像

フォルダー名の横でプロセスとターゲットを選び、**適用**を押します。別のオン・オフスイッチはありません。

以前に現像した写真を含め、そのフォルダーの全写真を再レンダリングします。プロセスとターゲットは新しい値になり、露出やコントラストなど他のユーザー補正は保ちます。適用の横には進捗バー、パーセント、完了枚数と総枚数が出ます。大量処理はレンダースロット数に合わせたキューで実行します。

## プリセットとコピー・ペースト

| 範囲 | 含まれる値 |
|---|---|
| ベース | フィルム種類とプロセス、ターゲット、スキャナープロファイル、フィルムベース |
| トーン | 露出、コントラスト、濃度、ハイライト・シャドウ、ホワイト・ブラック、カーブ |
| カラー | 色温度、ティント、彩度、ミキサー、グレーディング、白黒トーニング、フィルムエミュレーション |
| ディテール | グレイン、シャープネス、ハレーション、クラリティ、ビネット、ノイズ除去、GrainMend、部分補正 |
| ジオメトリ | クロップ、回転、上下左右反転、傾き補正、クロップ比率 |

全体ペーストはすべての範囲を使います。複数写真を選択している場合は選択全体に適用します。 ユーザープリセットも同じ完全な現像状態とジオメトリを保存します。

保存するときに名前を尋ねます。空欄なら空いている最初の番号で `プリセット N` が付き、すでにある名前を書いた場合は保存しません。

## スキャナープラグインがない場合

起動時にプラグインがなければ、ライブラリと現像の共通左サイドバーに、未インストール説明、 再検索、シミュレーターのブロックを自動表示しません。画像の読み込みはそのまま使えます。 再検索とシミュレーター機能を削除したわけではなく、スキャナー入口や設定から直接開けます。

## プリントレイアウトと出力枚数

プリントには、単一画像、コンタクトシート、ピクチャーパッケージ、カスタムパッケージ、 サイアノタイプ、ガラス乾板、ゼラチンシルバーの7レイアウトがあります。後ろの3つは単一画像と同じインスペクターを使います。複数写真を選ぶと、個別画像型の4レイアウトは完成したプリントページを縦に並べ、下へスクロールして次の写真を表示します。

書き出しとクイック書き出しの枚数は、選択した元画像ではなく完成ページで数えます。 39枚を6 × 7のコンタクトシートに置けば合成済みの1ファイル、4面パッケージなら10ページ、 初期カスタムパッケージなら1ページ、個別画像型なら制限付きバッチの39ファイルです。

パッケージ表示は既存のサムネイル、現像画像、元画像プレビューを再利用し、どれもない写真だけ小さな高速プレビューを作ります。最終出力ではメタデータから先に配置を計算し、各配置に必要なピクセルだけを現像します。同時準備は2～4画像に制限し、共有Core Imageコンテキスト、 最終ページまで接続した画像グラフ、ページ当たり512 MiBのソースラスタ上限を使います。

## プリントプロファイル

| 設定 | 画面 | プリント書き出し | 現像画面 |
|---|---|---|---|
| プリンター出力プロファイル | 出力結果を確認 | 完成したページ全体に適用 | 適用しない |
| C-printプルーフプロファイル | ラボと印画紙をソフトプルーフ | 配信用ファイルには焼き込まない | 適用しない |

出力プロファイルは、コンタクトシート、写真パッケージ、カスタムパッケージを一つのページに組んだ後で一度適用します。同じ写真の繰り返し配置や複数写真の混在でも、すべてに同じ変換が入ります。詳しくは[プリントレイアウトとC-printプレビュー](../reference/C_PRINT.md)を参照してください。

## 元のファイルへの影響

| 操作 | Finder の元ファイル | カタログと編集内容 |
|---|---|---|
| フォルダーの `×` | そのまま | そのフォルダーと写真をライブラリから外す |
| 写真を別のフォルダーへドラッグ | 移動する。名前が重なれば別名を付ける | 新しい場所へつなぎ直す |
| Finder での移動・名前変更 | ユーザーが変えた場所を保つ | ブックマークで自動的につなぎ直す |
| フォルダー単位の現像を適用 | そのまま | プロセスとターゲットを更新して描き直す |
| プリセット・コピー／ペースト | そのまま | 選んだ現像値と配置の値を更新 |
| プリント書き出し | そのまま | 別の出力ファイルとレンダー記録を作る |

## 2,000フレーム確認

大きなライブラリでは256枚を超えると長距離の自動スクロールを止め、表示に必要な行だけを作ります。2,000フレーム検査は24 MPから60 MP、3200 DPI、4800 DPIの資料を50フォルダーへ入れ、すべてのプロセスとターゲット、クロップ、方向を混ぜて現像と保存を確認します。

```bash
bash scripts/performance/run-virtual-library-stress.sh
```

この検査は通常の `swift test` では省略します。
