# スキャナーノイズプロファイル

[ドキュメントホーム](../README.md)

普通の写真1枚からノイズプロファイルは作れません。写真の高周波成分には、被写体とフィルムの粒子が混ざっているからです。

均一な、または階段状のターゲットを、同じ設定で3回以上スキャンします。同じ位置のピクセル値の変動が、信号レベルごとの分散になります。

- [ISO 15739:2023](https://www.iso.org/standard/82233.html) は、デジタル画像機器の信号ごとのノイズの測り方と報告の仕方を定めます。
- [ISO 21550:2004](https://www.iso.org/standard/35939.html) は、透過・反射スキャナーのダイナミックレンジの測り方を定めます。

ISO 15739 はデジタルカメラ向けです。negaflow は、スキャナーがこの規格に当てはまるとは主張せず、反復測定と信号ごとの分散という考え方だけを借ります。

> [!NOTE]
> 現在の同梱物に `holdoutValidated` の機器ノイズプロファイルはなく、自動で適用されるものはありません。既存プロファイルのテクスチャ値は、センサーのノイズ資料としては使いません。

## プロファイル1つの範囲

`ScannerNoiseProfile` は、次のすべてが同じときだけ一致と見なします。

- スキャナーのメーカーと機種
- 解像度（DPI）
- チャンネルあたりのビット深度
- カラーモード
- マルチ露光の使用の有無

似た機種や別の解像度の値は借りません。自動プロファイルが2つ以上ぴったり一致したときは、1つを選ばずに失敗します。

同じシーンの線形 RGB スキャン3枚以上から、チャンネルごとに次の式を当てはめます。

```math
\operatorname{variance}(x) = m_{\mathrm{shot}}x + b_{\mathrm{read}}
```

プロファイルには次も記録します。

- 校正資料の SHA-256
- 測定したフレーム数とサンプル数
- 観測した信号範囲
- 回帰の R²
- 検証済みのノイズ軽減の強さ

コードの最大強度は計算の破綻を防ぐだけで、品質の合格ラインではありません。

## 状態

| 状態 | 意味 | 自動適用 |
|---|---|---|
| `draft` | 測定や調整が終わっていない | いいえ |
| `measured` | 実機で反復測定した。独立した検証はない | いいえ |
| `holdoutValidated` | 別の検証資料で強さを確かめた | 完全に一致したときだけ |

自動で使うには、一致する `holdoutValidated` プロファイルがちょうど1つあり、校正・検証資料の SHA-256 とファイル構造の検査にも通る必要があります。`draft` と `measured` は、既存の一般設定を変えられません。

## 現状

リポジトリの NORITSU と SP-3000 のカラープロファイルには、実際のシーンから得た `texture` 値があります。この値には被写体、ピント、フィルムの粒子が混ざっているため、センサーのノイズ資料としては使えません。

繰り返し撮影した均一ターゲットと別の検証資料は、まだありません。検証済みの機器ノイズプロファイルは同梱しておらず、自動の経路は既存の一般設定を使います。

実際のプロファイルには次のすべてが必要です。

1. 同じ機器、解像度、ビット深度、カラーモード、マルチ露光設定での線形スキャン3枚以上
2. 校正資料のファイル一覧と SHA-256
3. 校正に使っていない検証シーンと、その SHA-256
4. ノイズ軽減と、ディテール・フィルム粒子の保持の比較
5. 実際のユーザーによる100%拡大の確認

実機でのキャプチャは `negaflow-scanner-sane` プラグインが担当します。SANE のオプションと機器制御のコードは、このリポジトリには入れません。
