# スキャナーノイズプロファイル

[ドキュメントホーム](../README.md)

ノイズプロファイルは普通の写真1枚からは作れません。 写真の高周波成分には被写体とフィルムグレインが混ざっています。

同じ設定で、平坦またはステップのあるターゲットを3回以上スキャンします。 同じ位置のピクセルがどれだけ動くかを見て、信号の明るさごとの分散を出します。

- [ISO 15739:2023](https://www.iso.org/standard/82233.html)は、デジタル撮像機器の信号ごとのノイズ測定と報告の方法を定めます。
- [ISO 21550:2004](https://www.iso.org/standard/35939.html)は、透過・反射スキャナーのダイナミックレンジ測定の方法を定めます。

ISO 15739はデジタルカメラ向けの規格です。negaflowはスキャナーも同じ規格だとは言いません。 繰り返し測定と信号ごとの分散という考え方だけを借りています。

> [!NOTE]
> 現在のバンドルには`holdoutValidated`の装置ノイズプロファイルがないため、自動適用されるものはありません。既存プロファイルの質感の数値をセンサーノイズの資料として使うこともしません。

## 1つのプロファイルが束ねる条件

`ScannerNoiseProfile`は、次がすべて同じときだけ一致とみなします。

- スキャナーの製造元とモデル
- 解像度DPI
- チャンネルあたりのビット深度
- カラーモード
- 多重露光を使うかどうか

似たモデルや別の解像度の値を借りることはありません。 完全に一致する自動プロファイルが2つ以上あるときは、選ばずに失敗させます。

同じ場面のlinear RGBスキャン3回以上から、チャンネルごとに次の式を当てはめます。

```math
\operatorname{variance}(x) = m_{\mathrm{shot}}x + b_{\mathrm{read}}
```

プロファイルに一緒に書く値:

- 校正資料のSHA-256
- 測定フレーム数と標本数
- 観測した信号範囲
- 回帰のR²
- 検証したノイズ除去の強さ

コード上の強さの上限は、おかしな計算を止めるための安全装置です。画質の合格ラインではありません。

## 状態

| 状態 | 意味 | 自動適用 |
|---|---|---|
| `draft` | 測定や調整が終わっていない | しない |
| `measured` | 実機の繰り返し測定はあるが独立した検証がない | しない |
| `holdoutValidated` | 別の検証資料で強さを確認した | 条件が完全に一致するときだけ |

自動で使うには、完全に一致する`holdoutValidated`プロファイルが1つだけ必要です。 校正資料と検証資料のSHA-256、ファイル構造の検査も通す必要があります。 `draft`と`measured`は既存の一般設定を変えられません。

## 今の状況

リポジトリのNORITSUとSP-3000のカラープロファイルには、実際の場面の`texture`値があります。 この値には被写体、ピント、フィルムグレインが混ざっているので、センサーノイズの資料には使えません 。

繰り返しの平坦ターゲットと別の検証資料はまだありません。 検証済みの装置ノイズプロファイルは同梱しておらず、自動経路は既存の一般設定を使います。

実際のプロファイルを入れるには、次がすべて必要です。

1. 同じ装置・解像度・ビット深度・カラーモード・多重露光設定でのlinearスキャン3回以上
2. 校正資料のファイル一覧とSHA-256
3. 校正に使っていない検証場面とそのSHA-256
4. ノイズ低減とディテール・フィルムグレイン保持を並べて比べた結果
5. 実際のユーザーによる100%拡大の確認

実機の取り込みは`negaflow-scanner-sane`プラグインが担当します。 SANEのオプションと装置制御コードはこのリポジトリに入れません。
