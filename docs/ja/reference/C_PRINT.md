# プリントレイアウトとC-printプレビュー

[ドキュメントホーム](../README.md)

プリント画面では、単一画像、コンタクトシート、ピクチャーパッケージ、カスタムパッケージ、 サイアノタイプ、ガラス乾板、ゼラチンシルバーを構成して書き出せます。

## コンタクトシート

新しいコンタクトシートの初期値は黒、6列×7行、横・縦の間隔は2 mmです。その他のレイアウトは白で始まります。すべてのレイアウトでシート色を黒・グレー・白から個別に選べ、キャプション、 自由テキスト、トンボ、ページ枠は背景に合わせて自動的に反転します。

余白、行・列数、横・縦の間隔は同じ実寸計算を使います。用紙に収まらない組み合わせは、 プレビューを壊さず有効な最大間隔に制限されます。自動方向は最初の写真ではなくグリッドを基準に決まります。**全体を表示**では写真全体を残すためセル内に空きが生じる場合があり、 **セルを塗りつぶす**では共通セルに合わせて切り抜き、見た目の間隔を一定にします。

キャプションはファイル名、元のフレーム番号、現在の画像順を1から振り直す連番、評価、 ユーザー入力に対応します。画像ごとのキャプションは左・中央・右に揃えられます。ユーザー入力は複数のテキストボックスを追加でき、各テキストの内容、揃え、位置、幅、高さを個別に指定できます。

## 用紙設定とルーラー

すべてのレイアウトは同じ用紙設定を使います。3.5 × 5から24 × 36までの写真用インチ判、 Letter、Tabloid、A3+、ISO A1〜A6、ISO B1〜B6を選べます。表面はシート色の直下にあり、 マット、光沢、ラスター、シルクに対応し、初期値はマットです。

ルーラーは初期状態ではオフです。オンにすると直下にin/cmの切り替えが現れ、用紙の上と左に水平・垂直ルーラーを表示します。1 inまたは1 cmごとに小さな数字と補助目盛りを描きます。

## 1枚ずつ表示する歴史的プリントレイアウト

単一画像、サイアノタイプ、ガラス乾板、ゼラチンシルバーは、選択した写真ごとに1ページを作成します。複数の写真を選ぶと、1枚のシートにまとめず、ページを縦に並べてスクロール表示します。サイアノタイプは輝度を青の単色階調に、ガラス乾板はモノクロネガに、ゼラチンシルバーは中性のモノクロポジに変換します。

3つのレイアウトは単一画像と同じ用紙、方向、余白、出力設定、インスペクターを使い、 書き出しとクイック書き出しにも同じ表現をレンダリングします。特定の時代の薬品、乾板、 印画紙、観察条件を実測して再現する装置精度シミュレーションではありません。

## プリントを書き出す

クイック書き出しの直下にある**プリントを書き出す**は、用紙サイズ、向き、余白、レイアウト、 黒・グレー・白のシート、キャプション、自由テキスト、トンボをレンダリングします。ファイル形式、DPI、 フォルダ、名前、納品色空間は書き出し設定を使います。色域警告、ソフトプルーフ表示、 印画紙表面の光沢など画面確認専用の要素はファイルに焼き込みません。

プリント書き出しまたはクイック書き出しの実行中は、不確定の円形表示ではなく、完了ページ数、 線形プログレスバー、パーセントを表示します。

### 出力ページ数とレンダリング

出力数は完成ページ単位です。39枚を6列×7行にしたコンタクトシートは合成済みの1ページ、 4面付けのピクチャーパッケージは10ページ、既定のカスタムパッケージは1ページ、1枚ずつ表示する4レイアウトは、クイック書き出しと同じ上限付きバッチ処理で39ファイルになります。

パッケージプレビューは写真ごとに対話用と確定用のフル解像度プレビューを生成しません。 既存画像を再利用し、不足分だけサムネイルサイズの高速プレビューを作ります。最終出力は元画像メタデータから配置を計算し、各配置に必要な画素だけを現像し、ページ内の固有ソースを一度に2〜4件ずつ準備します。共有Core Imageコンテキスト、最終ページまでつながるグラフ、 ページ当たり512 MiBのソースラスタ上限で、見た目と出力規則を変えずにメモリを制限します。

### プリンター出力プロファイル

プリント画面で選んだプリンター出力プロファイルは、実際のプリント書き出しに適用されます。 ページ全体を先に合成し、完成したページにプロファイルを一度適用します。同じ写真を繰り返すピクチャーパッケージでも、複数の写真を組み合わせるカスタムパッケージでも、すべての配置が対象になります。

このプロファイルはライブラリや現像のプレビューには影響しません。変更が反映されるのはプリントのプレビューとプリント書き出しだけです。

## C-printの使い方

出力方式には標準出力とC-printがあります。C-printはラボと印画紙を記録し、ラボが提供する RGB ICCプロファイルで画面上のソフトプルーフを作成します。共通の表面設定は出力方式やレイアウトにかかわらずレイアウトタブにあります。測定済みのプロファイルがない場合、 任意の「C-print風」の色は適用しません。

1. プリント画面の出力方式で **C-print** を選びます。
2. ラボと印画紙を入力します。必要ならレイアウトタブで表面を選びます。
3. そのラボ、印画紙、装置用に提供されたRGB ICCプロファイルを選びます。
4. プリントプレビューをオンにします。用紙と黒点のシミュレーション、色域警告は詳細にあります。

有効なRGB ICCプロファイルがなくても出力先設定は保存されますが、プリントプレビューは利用できません。このRGBプレビュー経路では、CMYKおよびdevice-linkプロファイルは受け付けません。

## カラー処理の原則

C-printのプルーフICCは画面確認専用です。書き出すファイルのピクセルや埋め込みプロファイルには適用されません。別のプリンター出力プロファイルを選んでいない場合、プリント書き出しには書き出し設定に表示される納品色空間を使用します。 ソフトプルーフ用プロファイルが納品プロファイルとして暗黙に使われるのを防ぐためです。

従来の `PRINT` 現像targetは別機能として残ります。この経路では有効なRGB printer-class ICC が必要で、そのプロファイルを通して出力します。

## 精度の限界

プレビューにはICC変換が適用され、用紙の白、黒点、色域外の色を任意で確認できます。精度は、 調整済みのディスプレイと現在のラボ工程に合ったプロファイルに依存します。観察光、薬品の変化、 装置の調整状態、印画紙ロットの差は予測できません。negaflowはラボプロファイルを内蔵したり、 推測で作成したりしません。
