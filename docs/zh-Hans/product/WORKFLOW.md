# 从图库到印相

[文档首页](../README.md)

本指南涵盖导入、文件夹显影、设置传递、扫描仪缩略图和印相输出。图库里的文件夹对应每个源文件实际所在的父文件夹。

> [!IMPORTANT]
> 除非你明确把照片移到另一个文件夹，否则源文件保持不变。把文件夹从图库移除，与在 Finder 里删除文件，是两件不同的事。

## 导入

导入控件下方会显示进度条、百分比、已完成数量和总数。元数据在主线程之外读取，新画幅则一并登记，所以大文件夹不会反复重建图库索引。

导入照片的自动显影**默认关闭**。导入的过程如下：

1. 登记源文件。
2. 先出现原始缩略图和文件夹。
3. 给文件夹应用流程和目标，或进入显影界面时，显影才开始。

要让每次导入都自动显影，请打开**设置 → 工作流 → 自动显影新导入的照片**。该选择会在多次启动之间保留。它只作用于这次导入登记的画幅，不会替换已有的显影状态。已显影的照片只有在你明确点文件夹的**应用**或粘贴设置时才会重新处理。

扫描仪采集不同：胶片类型、流程和目标在扫描时已选定，所以扫描结果发布后就开始显影。显影和印相的胶片条对彩色负片、正片、黑白负片和黑白正片的源文件显示已显影的缩略图。图库则保留源缩略图，便于核对源文件。

## 文件夹列表

- 折叠和展开的状态会保留。新建文件夹或重新打开应用，都不会展开其他文件夹。
- 每个文件夹行都有同样的 `×` 控件。它只把该文件夹及其照片从**图库**中移除，源文件仍在 Finder 里。
- 显影界面中文件夹内的照片列表有自己高度受限的滚动区域，列表再长、窗口再小，也不会把侧边栏的其余部分挤走。

### 把照片移到另一个文件夹

把一张或选中的多张照片拖到另一个文件夹行，会移动实际文件并同时更新目录。导入的文件夹、应用创建的文件夹以及含有扫描仪采集的文件夹，适用同样的规则。

目标位置已有同名文件时不会覆盖。如果 `frame.tiff` 已存在，negaflow 会依次尝试 `frame 2.tiff`、`frame 3.tiff`，以此类推。扫描仪源文件附带的 IR 文件会在同一个事务里一起移动。

### 在 Finder 里的变动

negaflow 监视已登记的实际源文件夹。经过一小段防抖后，一旦发现以下情况，只会重新扫描有变动的文件夹：

- 源文件被移动或重命名
- 已登记的文件夹被移动或重命名
- 已登记的文件夹里直接新增了图像

源文件的持久书签能解析出新位置时，已有的画幅会被重新链接。移动过的文件夹保留其文件夹 ID 和添加日期。新增的文件会被导入，不会与已知文件重复。

这是事件驱动的文件夹监视，而不是定期扫描整个图库。实际父文件夹相同的画幅共用一个监视，只检查报告了变动的文件夹。

## 按文件夹显影

在文件夹标题旁选择流程和目标，然后点**应用**。没有单独的开关。

应用会重新渲染文件夹里的每张照片，包括之前已显影的。会使用新的流程和目标，曝光、对比度等其他用户调整则保留。如果某个画幅正在渲染，文件夹任务会等那次渲染结束。

应用旁边显示进度条、百分比、已完成数量和总数。大批量时只保持与渲染槽位数量相同的工作线程，而不是为每张照片启动一个任务。

## 拉直与变换

在显影界面右侧打开 几何 → 裁剪。按住 ⌘（Windows 上为 Ctrl）沿应当水平的边缘拖动，松开后照片会旋转，使这条线变成水平。画得更接近竖直的线会被校正为垂直。按住 ⌥（Windows 上为 Alt）时，裁剪框上会显示细网格。两个键都可以在 设置 → 快捷键 中更改，但不能设为同一个键。Mac 上 ⌃ 单击等于右键单击，所以参考线不能选 ⌃。

变换部分位于 校准 和 细节与效果 之间。关 不改动照片。自动、水平、垂直、完全 会在照片中找一次直线并据此校正。水平 只旋转照片，垂直 还会把向上汇聚的竖线立直，完全 同时校正垂直和水平透视。自动 与 完全 做同样的事，但会抑制幅度大的校正。引导 按你在照片上画的 2–4 条参考线校正。

垂直、水平、旋转、长宽比、缩放、X 偏移、Y 偏移 滑块叠加在模式求得的值上。双击滑块即可复位。开启 限制裁剪 后，结果会裁成没有空白角的最大矩形。旋转 90° 或翻转后校正会跟着保留，重置所有调整 会把它与裁剪、拉直一起清除。

## 预设与复制粘贴

显影设置有七个可以独立选择的分组。

| 分组 | 内容 |
|---|---|
| 输入伽马 | 源传递特性的解释 |
| 片基缩放 | 片基的缩放 |
| 基础 | 胶片类型与流程、目标、扫描仪配置文件、片基、通道范围校准、自动平衡、自动色阶和中性平衡 |
| 影调 | 曝光、对比度、密度、高光、阴影、白色色阶、黑色色阶和影调曲线 |
| 色彩 | 色温、色调、色深、自然饱和度、饱和度、混合器、分级、校准、黑白调色和胶片模拟 |
| 细节 | 颗粒、锐化、光晕、清晰度、暗角、降噪、GrainMend 强度和局部调整 |
| 几何 | 裁剪、旋转、水平和垂直翻转、拉直、裁剪比例和变换 |

完整粘贴或用户预设会替换目标的显影设置。限定范围的粘贴只替换所选分组的有效值，保留其余部分。只粘贴风格的一部分时，其影调、色彩和纹理的贡献会并入数值，并清除对风格的引用，避免旧风格被再次叠加。反复粘贴同样的设置，得到的状态相同。菜单、快捷键和面板使用同样的粘贴范围。

粘贴和用户预设作用于所有选中的照片。一次撤销或重做覆盖整个选择，Windows 会先验证所有目标，再做修改。缩略图和当前预览会按新配方刷新。源文件、星级和绑定到源文件的缺陷编辑不会被复制。

用户预设保存完整的显影状态和几何。不含几何的旧预设或粘贴范围，为兼容起见会包含几何。名称留空时，使用第一个空闲的带编号名称，保存也不会仅因名称相同就覆盖已有预设。

## 没有扫描仪插件时

启动时如果没有安装扫描仪插件，共用的图库和显影侧边栏不会自动显示缺少插件的说明、重新扫描控件或模拟器区块。图像导入仍然可用。

扫描仪重新扫描和模拟器支持仍然存在，可以通过扫描仪入口和设置使用；安装插件或明确启用模拟器后，现有的扫描仪界面就会出现。

## 印相版式与输出数量

印相有八种版式：单张图像、接触印相表、照片套版、自定义套版、蓝晒、玻璃干版、明胶银盐和水印。五种单页类版式为每张选中的照片显示一页成品，纵向滚动。水印是独立的版式，其他版式保留原有控件。

导出和快速导出按成品页数计数。例如，39 张照片的 6 × 7 接触印相表是一个合成文件，四联照片套版是 10 页，默认的自定义套版是一页，五种单页类版式则通过有界批处理生成 39 个文件。

套版预览复用已有的缩略图、已显影图像或 RAW 预览，只在都没有时才生成小的快速预览。最终导出根据源文件元数据计算每个位置，只显影该位置需要的像素，同时准备两到四个源文件，并在最后渲染页面之前保持 Core Image 图形连接。共享的渲染上下文和每页 512 MiB 的源光栅预算，防止一页膨胀成无限多的全分辨率中间图像。

## 印相水印

在版式类型菜单里，明胶银盐之后选择水印。它在每张照片下方增加边框，不裁剪照片，也可以在上方增加等高的边框。照片纸张尺寸随照片加边框而定。

底部边框左侧显示相机，镜头在其下方。右侧显示徽标，然后是焦距、光圈、快门速度和 ISO，日期在下方。打开徽标可添加一个；没有选择文件时，使用 negaflow 徽标。negaflow 不附带厂商徽标，请自己选择 JPEG、PNG 等图像文件。设置和模板只保存文件路径。绘制时会检查该文件，大小和修改时间不变时复用缓存的徽标。如果文件被移动或删除，只会省略徽标，底部的状态点和诊断报告会记录这件事。空的相机、镜头、曝光和日期栏保持为空，只绘制输入的文字。文字很长或边框很窄（例如竖幅照片）时，边框内的所有项目按同一比例缩小，文字不会超出照片，也不会被截断。

边框可以是白色、黑色或照片的模糊背景。白色时文字为黑色，第二行为灰色；黑色时所有文字为白色；模糊时可为文字和直方图选择黑色或白色。直方图用点状柱绘制。名称和直方图的位置规则见[印相布局与 C-print 预览](../reference/C_PRINT.md)。模糊背景和直方图在有可用的胶片条缩略图时复用它，否则使用缩小的照片图像。模板会保存纸张颜色和全部水印设置，包括文字和徽标路径。

## 印相配置文件

印相里的 ICC 控件各有各的作用。

| 设置 | 屏幕预览 | 印相导出 | 显影预览 |
|---|---|---|---|
| 打印机输出配置文件 | 显示印相结果 | 应用于成品页面 | 从不应用 |
| C-print 打样配置文件 | 对冲印店和纸张的工艺做软打样 | 不写进交付文件 | 从不应用 |
| 通用软打样 | 在其设定的显示范围内使用 | 仅作显示辅助 | 遵循自己的设置 |

打印机输出配置文件不会在某张源图被复制之前就应用到它上面。接触印相表、照片套版或自定义套版先组成，然后对整页只应用一次该配置文件。因此，重复放置同一张源图的版式和混排多张源图的版式，得到相同的输出转换。

C-print 打样配置文件是冲印店提供的工艺预览，不会被悄悄替换成输出配置文件。配置文件的要求和精度边界见[印相布局与 C-print 预览](../reference/C_PRINT.md)。

## DNG 导出

DNG 把显影后的画面写成未压缩的 16 位线性 RGB 文件（`PhotometricInterpretation = LinearRaw`），色彩空间为你选的输出空间：sRGB、Display P3 或 Adobe RGB。影调和色彩已经固化在里面，所以其他应用把它当作输出参考文件来读。文件按与 TIFF 相同的元数据策略携带版权、扫描仪、软件、日期和胶片备注。不会复制源相机的 EXIF、IPTC 和 GPS。每个像素占 6 字节，因此 2400 万像素的画幅约为 144 MB。

DNG 适用于未压缩的源文件：TIFF、相机 RAW 和 DNG。JPEG、PNG 和 HEIC 源文件不能导出为 DNG。显影、`PRINT` 目标和印相版式都支持 DNG。印相 DNG 以带 ColorMatrix 的标准 RGB 记录组好的页面，并跳过打印机 ICC 转换。DNG 导出使用在导出里选定的文件夹，并保留 `.dng` 扩展名。最终文件发布并通过检查才算完成。exiftool 和 Apple 的图像解码器可以读取该文件。在其他 RAW 编辑软件中的渲染效果没有测量过。

## 哪些操作会改变源文件

| 操作 | Finder 里的源文件 | 目录与编辑 |
|---|---|---|
| 文件夹的 `×` | 保留 | 文件夹和照片从图库移除 |
| 拖到另一个文件夹 | 移动；重名时选用新名称 | 重新链接到新位置 |
| 在 Finder 里移动或重命名 | 保留用户的改动 | 通过书签自动重新链接 |
| 应用文件夹显影 | 保留 | 流程和目标更新后重新渲染 |
| 预设或复制粘贴 | 保留 | 所选的显影和几何数值更新 |
| 印相导出 | 保留 | 生成单独的输出文件和渲染记录 |

## 大型图库检查

照片超过 256 张时，每次选择变化后，胶片条不再做长距离的自动滚动。可见的卡片和文件夹行按需创建。

2,000 画幅的压力检查在 50 个文件夹里导入 24 MP、40 MP、60 MP、3200 DPI 和 4800 DPI 的像素样本。它混合所有流程和目标，让彩色负片占一半以上，应用裁剪和方向变更，然后验证显影、缩略图和目录往返。在 `negaflow-mac/` 下运行：

```bash
bash scripts/performance/run-virtual-library-stress.sh
```

压力检查需要手动开启，普通的 `swift test` 会跳过它。
