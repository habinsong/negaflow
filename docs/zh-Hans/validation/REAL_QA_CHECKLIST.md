# 实机检查表

[文档首页](../README.md)

这些是自动测试和构建确认不了的项目。最终画面确认和真实设备确认由用户负责。
适用的必填项都有结果和依据，才能批准发布候选。

结果写成 `PASS`、`FAIL`、`BLOCKED`、`N/A` 之一。`FAIL`、`BLOCKED`、`N/A` 要写理由。

> [!IMPORTANT]
> 没填这张表的构建，不会标注为已完成实机、最终画质、签名和公证确认。自动测试通过不能替代这项
> 检查。
