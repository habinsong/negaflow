# GrainMend IR 实际扫描测量

[文档首页](../README.md)

GrainMend IR 到底能去掉多少缺陷，用真实扫描而不是合成样本测出来的结果。

| 项目 | 值 |
|---|---|
| 素材 | Epson GT-X900，彩色负片，2400dpi，16 位 |
| 配对 | 5 组（正式扫描与红外通道） |
| 计分缺陷 | 每帧 140 到 338 个 |
| 测量日期 | 2026-08-11 |

## 如何计分

不让检测器给自己打分。只有照片能确认的才算缺陷：把红外候选按该缺陷自身的局部偏移对到 red 通道
的暗痕上，只有那个峰值高出周围噪声四个西格玛时才保留。去除率是缺陷中心的对数密度超出量，以环形
基线为参照，在校正前后各测一次。过校正就是同一个数变成负值，也就是中心比周围更亮了。

## 先把采集做对

红外通道必须带着与正式扫描相同的伽马表和焦点。保持设备默认值时，片基会在白端被切掉（画面的
9.07% 钉在 65535），用来衡量缺陷深度的基线就没有了。两个通道设成一样时，截断为零。在这个修正
之前测到的数字说明不了检测器的任何问题。

## 结果

| 帧 | 候选到确认 | 倍率 | 中心去除率 | 过校正 轻微/中等/严重 |
|---|---|---|---|---|
| 19 | 483 → 262 | 1.12 | 90% | 5 / 0 / 0 |
| 20 | 726 → 407 | 1.84 | 85% | 16 / 8 / 3 |
| 21 | 1138 → 494 | 1.52 | 96% | 24 / 5 / 0 |
| 22 | 969 → 674 | 1.26 | 93% | 25 / 3 / 3 |
| 23 | 540 → 341 | 1.32 | 95% | 13 / 2 / 0 |

倍率是可见光密度除以红外密度的实测值。遮挡在波长上几乎是平的，所以接近 1 的值说明两个通道对
“被挡住了什么”给出了一致的答案。轻微指中心比周围亮 1 到 3 个百分点，低于胶片颗粒；严重指超过
6 个百分点。检测每帧 0.6 到 0.9 秒，施加校正再花 0.1 到 0.3 秒。

校正量的 96% 到 99% 落在真实红外缺陷的八个像素以内，按 red 十分位统计的平均校正量也没有趋势，
说明放宽后的检测没有渗到画面里。

## 按缺陷大小

以前是宽的灰尘留着、划痕干净。四个步骤只在大于几个像素的缺陷上出错，第五个则让所有缺陷都少去
掉了固定的一部分。

| 短边半径 | 之前 | 之后 |
|---|---|---|
| 1 到 2 px | 52 到 74% | 77 到 95% |
| 3 到 4 px | 77 到 89% | 93 到 99% |
| 5 到 7 px | 0 到 91% | 24 到 99% |
| 12 到 17 px | 0 到 73% | 58 到 89% |
| 18 px 以上 | 0% | 73 到 93% |

- 基线的结构元素按第一遍观测到的缺陷大小放大，但那次观测本身就用同一条基线做的，所以比结构
  元素更宽的缺陷量到的是自己的内部，看起来很小。现在直接由分辨率决定。
- 候选阈值是单个像素的显著性，所以又淡又宽的灰尘一个像素也过不了。现在把同一显著性水平按缺陷
  覆盖的面积来用。
- 零假设分布取自整个搜索面，于是和搜索面一样大的缺陷成了自己的零假设，量到的倍率减半。
- 要还原的量是从三西格玛的判定线量的，而不是从胶片自身的底线，这让每个缺陷都留下了那一段。
- 因为“大”而被选中的峰值有向上的偏差，之前固定减去一个西格玛。那个偏差是四西格玛门限的逆米尔斯
  比：在门限处照旧谨慎，超过八西格玛就不再削减。

## 尚未确认

- 没有用眼睛看过校正后的画面。这里的轻微过校正是数字，不是对观感的判断。
- 没有在应用里跑完整的 18 张批量。
- 第 20 帧仍然只有 85%，低于其他。它的红外密度只有其他帧的六成左右，输入本身可能就偏薄。
- 只有一台扫描仪。V800、V850、Coolscan 都没有测过。
- 低分辨率彩色 16 位扫描在 300dpi 及以下会全黑。2400dpi 正常，未确认对产品的影响，原因不明。
