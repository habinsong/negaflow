# 扫描仪噪声配置文件

[文档首页](../README.md)

一张普通照片做不出噪声配置文件，因为照片的高频部分混有被摄体和胶片颗粒。

用同样的设置，把均匀或阶梯形的目标至少扫描三次。同一位置像素值的变化，给出各信号水平上的方差。

- [ISO 15739:2023](https://www.iso.org/standard/82233.html) 规定了数字成像设备按信号测量和报告噪声的方法。
- [ISO 21550:2004](https://www.iso.org/standard/35939.html) 规定了透射和反射扫描仪动态范围的测量方法。

ISO 15739 针对数码相机编写。negaflow 不声称扫描仪适用该标准，只借用重复测量和按信号求方差的思路。

> [!NOTE]
> 当前内置资源里没有 `holdoutValidated` 的设备噪声配置文件，所以没有任何配置会自动应用。现有配置文件里的纹理数值不当作传感器噪声数据使用。

## 一个配置文件的适用范围

只有下列各项全部相同，`ScannerNoiseProfile` 才算匹配：

- 扫描仪厂商和型号
- 分辨率（DPI）
- 每通道位深
- 色彩模式
- 是否开启多重曝光

不借用相近型号或其他分辨率的数值。如果有多个自动配置文件完全匹配，就报错，不会任选其一。

用同一场景至少三张线性 RGB 扫描，按通道拟合下式：

```math
\operatorname{variance}(x) = m_{\mathrm{shot}}x + b_{\mathrm{read}}
```

配置文件还会记录：

- 校准资料的 SHA-256
- 测量的帧数和样本数
- 观测到的信号范围
- 回归 R²
- 经过验证的降噪强度

代码里的最大强度只是防止计算出错，不是质量合格线。

## 状态

| 状态 | 含义 | 自动应用 |
|---|---|---|
| `draft` | 测量或调整尚未完成 | 否 |
| `measured` | 在真实设备上重复测量，没有独立验证 | 否 |
| `holdoutValidated` | 强度已用单独的验证资料检验 | 仅在完全匹配时 |

自动使用要求恰好有一个匹配的 `holdoutValidated` 配置文件，并且校准和验证资料的 SHA-256 以及文件结构检查都要通过。`draft` 和 `measured` 不能改变现有的通用设置。

## 现状

仓库里的 NORITSU 和 SP-3000 彩色配置文件带有来自真实场景的 `texture` 数值。这些数值混有被摄体、对焦和胶片颗粒，不能当作传感器噪声数据。

反复拍摄的均匀目标和单独的验证资料目前都没有。内置资源里没有经过验证的设备噪声配置文件，自动路径使用现有的通用设置。

真正的配置文件需要同时具备：

1. 同一设备、分辨率、位深、色彩模式和多重曝光设置下的三张以上线性扫描
2. 校准资料的文件清单和 SHA-256
3. 未用于校准的验证场景及其 SHA-256
4. 降噪与细节、胶片颗粒保留的对比
5. 真实用户在 100% 缩放下的检查

真实硬件上的采集由 `negaflow-scanner-sane` 插件负责。SANE 选项和设备控制代码不放进本仓库。
