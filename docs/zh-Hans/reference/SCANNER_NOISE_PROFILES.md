# 扫描仪噪声配置文件

[文档首页](../README.md)

噪声配置文件没法从一张普通照片做出来。照片的高频成分里混着被摄体和胶片颗粒。

要用相同设置，把平坦或阶梯标板至少扫三次。看同一位置的像素抖动多少，得出各信号亮度下的方差。

- [ISO 15739:2023](https://www.iso.org/standard/82233.html) 规定数字成像设备按信号测量和报告
噪声的方法。
- [ISO 21550:2004](https://www.iso.org/standard/35939.html) 规定透射和反射扫描仪动态范围的
测量方法。

ISO 15739 是给数码相机写的。
negaflow 并不主张扫描仪适用同一标准，只借用重复测量和按信号求方差的思路。

> [!NOTE]
> 当前内置包里没有 `holdoutValidated` 的设备噪声配置文件，因此没有会自动应用的。也不会把既有
> 配置文件里的纹理数值当作传感器噪声资料用。

## 一个配置文件覆盖的条件

只有下面这些全都相同，`ScannerNoiseProfile` 才算匹配。

- 扫描仪厂商和型号
- 分辨率 DPI
- 每通道位深
- 色彩模式
- 是否开多重曝光

不会借用相近型号或别的分辨率的数值。完全匹配的自动配置文件多于一个时，不做选择，直接失败。

用同一场景的 linear RGB 扫描三次以上，按通道拟合下式。

```math
\operatorname{variance}(x) = m_{\mathrm{shot}}x + b_{\mathrm{read}}
```

和配置文件一起写下的值：

- 校准素材的 SHA-256
- 测量帧数和样本数
- 观测到的信号范围
- 回归 R²
- 验证过的降噪强度

代码里的强度上限只是拦住异常计算的保护，不是画质合格线。

## 状态

| 状态 | 含义 | 自动应用 |
|---|---|---|
| `draft` | 测量或调整没做完 | 不用 |
| `measured` | 有实机重复测量，但没有独立验证 | 不用 |
| `holdoutValidated` | 用独立验证素材确认过强度 | 只有条件完全匹配时 |

自动使用需要恰好一个完全匹配的 `holdoutValidated` 配置文件。
校准素材和验证素材的 SHA-256、文件结构检查也都要通过。
`draft` 和 `measured` 改不了既有的通用设置。

## 现在的情况

仓库里 NORITSU 和 SP-3000 的色彩配置文件带有真实场景的 `texture` 值。
这些值混着被摄体、对焦和胶片颗粒，当不了传感器噪声资料。

重复扫的平坦标板和独立验证素材还没有。
所以没有内置经过验证的设备噪声配置文件，自动路径用的是既有通用设置。

要放进真正的配置文件，下面这些都得有。

1. 设备、分辨率、位深、色彩模式、多重曝光设置都相同的 linear 扫描三次以上
2. 校准素材的文件清单和 SHA-256
3. 没用于校准的验证场景及其 SHA-256
4. 把降噪效果和细节、胶片颗粒保留放在一起比较的结果
5. 真实用户在 100% 放大下的确认

实机采集由 `negaflow-scanner-sane` 插件负责。 SANE 选项和设备控制代码不放进本仓库。
