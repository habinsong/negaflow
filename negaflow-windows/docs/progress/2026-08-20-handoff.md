## 3. ☠️ 확인 못 한 것 · 새로 찾은 것

### 3.1 `native.gpu_film_scan` 이 가끔 **SEGFAULT** 로 죽습니다 (원인 미확정)

- 실측: `ctest --preset x64-release -R native.gpu_` 를 **27회** 돌려 **3회** 실패.
  언제나 같은 시험, 언제나 `***Exception: SegFault`.
- 앱이 떠 있든 아니든 났습니다. 스택은 **아직 못 잡았습니다**(Release, PDB 미배포).
- **다음 사람: 이것부터 잡으십시오.** 시험이 가끔 빨간 상태는 진짜 결손을 가립니다.
  `ctest -R native.gpu_film_scan --repeat until-fail:50` 로 재현한 뒤 디버거를 붙이거나,
  `gpu_film_scan_stage.cpp` 의 자원 수명(장치·컨텍스트 공유)을 의심해 보십시오.
