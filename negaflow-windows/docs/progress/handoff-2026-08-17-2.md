## 5. 실측 — 속도

| 단계 | 처음 | 지금 | 목표 |
|---|---:|---:|---:|
| TIFF 디코드 + ICC | 2,730 ms | 2,695 ms | 1,500 ms |
| 현상 | 770 ms | 770 ms | 200 ms |
| **검출** | **18,560 ms** | **8,932 ms** | **2,500 ms** |
| **합계** | **22,059 ms** | **12,397 ms** | **5,000 ms** |

앱에서 처음 쟀을 때는 **43,420 ms** 였습니다(다운스케일 + 풀프레임 미세입자 재계산).

검출 8,932 ms 의 CPU 작업(12타일 합계, 워커 4):

| 단계 | CPU 합계 | 비중 |
|---|---:|---:|
| 먼지 형태학 | 14,990 ms | 47% |
| 미세 입자 | 11,135 ms | 35% |
| 스크래치 각도 | 2,058 ms | 6% |
| 검출 이미지 생성 | 840 ms | 3% |
| 증거 조립 | 602 ms | 2% |
| 봉합 + 성분 | 115 ms | <1% |

**`opening`/`closing` 하나가 82%.** 먼지와 미세 입자가 같은 원시연산을 씁니다.

### 5.1 GPU

macOS 는 CoreImage + Accelerate(vImage) 로 돕니다 — GPU/SIMD 입니다. 알고리즘은 이미 최적
(van Herk/Gil-Werman, 화소당 O(1))이라 **알고리즘이 아니라 실행 장치가 차이**입니다.

**선택: Direct3D 11 컴퓨트 셰이더.** Microsoft 가 만들고 모든 벤더가 구현, Windows 기본 포함,
내장·외장 무관. 다운레벨(10.0/10.1)은 `CheckFeatureSupport` +
`D3D11_FEATURE_D3D10_X_HARDWARE_OPTIONS` 로 확인하고, 안 되면 CPU 폴백(WARP 는 정합성
확인용). 근거와 탈락 후보(OpenCL/CUDA/Vulkan/DirectML)는 `02` 문서 4.1 절.

**요구 범위는 검출만이 아닙니다** — 현상·프리뷰·보정·우측 슬라이더·인화까지. `02` 문서
4.3 절에 13단계 우선순위표가 있습니다. 우선순위 0 = 형태학, 1 = 톤/곡선/믹서/그레이딩(슬라이더
체감), 1 = 프리뷰 리샘플.

### 5.2 GPU 전에 걷어낼 CPU 낭비

1. `bipolar_top_hat` 이 호출마다 `std::vector<float>` 할당 (타일당 36개 × 12타일)
2. `find_candidates` 의 각도 워커가 **2로 고정** (`clamp(hw, 1, 2)`)
3. 타일 동시 실행이 4로 고정 (16스레드 기계) — 재보고 정할 것
4. `std::async` 대신 고정 스레드 풀

## 9. 함정 (이번 세션에 실제로 겪은 것)

| 함정 | 증상 | 대응 |
|---|---|---|
| **앱 인스턴스 여러 개** | 라이브러리가 **0장**으로 보임 | 같은 카탈로그를 두 프로세스가 잡습니다. 하나만 남기면 즉시 복구. **데이터는 안전했습니다** — DB 파일은 그대로였고 15개 파일명이 다 들어 있었습니다 |
| `open_application` 반복 호출 | 위 상황을 만듦 | 한 번만 부르십시오 |
| **MSBuild 낡은 오브젝트** | 시그니처 바꾼 뒤 LNK2019 | 해당 `.obj` 삭제 또는 소스 타임스탬프 갱신. `negaflow_imaging.lib` 를 "최신"으로 보고 다시 컴파일하지 않습니다 |
| `run-app.ps1` 을 상대경로로 백그라운드 실행 | "term is not recognized" | 절대경로로 |
| `--defect-tools` 가 `frame unavailable` | 디스패처가 큐를 안 돌림 | 앱 종료 후 단독 실행. **앱이 켜진 채 프로덕션 저장소에 대고 돌리지 말 것** |
| 라이브러리 그리드에서 썸네일 클릭 | 의도와 다른 프레임이 열림 | 파일명 확인하고 클릭 |
| 화면 조작 중 포커스 상실 | `The desktop shell is frontmost` | `open_application` 후 곧바로 batch. 그래도 안 되면 배치를 나누지 말 것 |

    `ScannerTargetGrade` → IT8 → 나머지 (`08` 문서)
