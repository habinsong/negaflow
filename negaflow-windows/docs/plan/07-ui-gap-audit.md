## 5. 정렬·분류 — "되는 것처럼 포장된" 것

| # | 항목 | 판정 | 확인해야 할 것 |
|---|---|---|---|
| 5.1 | 정렬 **방향** 토글 | **없음** | macOS `↑ 입력순` 의 화살표가 오름/내림입니다. Windows 에는 방향 개념이 안 보입니다 |
| 5.2 | 정렬 기준 목록 | **미확인** | macOS `LibraryPresentation.swift` 의 항목 전부가 Windows 드롭다운에 있는지, 그리고 **고르면 실제로 순서가 바뀌는지** |
| 5.3 | 필름스트립 범위(`전체`) | **미확인** | macOS `FilmstripScope.swift` — 전체/폴더/롤. 고르면 실제로 바뀌는지 |
| 5.4 | 라이브러리 필터 메뉴 | **미확인** | `library_filter_menu_all_options.png` 의 항목이 전부 있는지, 눌러서 결과가 바뀌는지 |
| 5.5 | 빠른 필터(현재 롤·필름 종류·별점·오프라인) | **미확인** | 라이브러리 하단 `전체 / 폴더별 / 필름 ⌄ / 오프라인` |

"UI 만 있고 기능 없음" 으로 이 표에 적고, 고칠 때까지 **그 컨트롤을 비활성으로 두는 것이
