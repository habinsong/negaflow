# ADR-0028: 소프트 프루프는 미리보기에만 존재하고, v2 프로파일의 흰색은 색소에서 재구성한다

기준일: 2026-08-10

## 상태

채택.

## 배경

macOS `SoftProof` 를 옮기면서 두 가지가 걸렸습니다.

**첫째, 이것이 인화물에 실리면 안 됩니다.** macOS 에서 프루프는 `renderDisplayCGImage` 안에서만
걸리고 `ExportEngine` 과 `PrintPackageRenderer` 는 부르지 않습니다. Windows 제품 계약에도
"preview 와 export 가 같은 레시피와 수학을 쓴다" 가 있으므로, 프루프를 레시피에 넣으면 그 계약과
정면으로 부딪칩니다.

**둘째, 계산을 그대로 옮기는 것만으로는 macOS 와 같은 결과가 나오지 않습니다.** macOS 는
프로파일을 `CGColorSpace.copyICCData()` 로 받으므로 `wtpt` 가 이미 D50 PCS 흰색입니다. Windows
는 파일을 그대로 읽고, ICC v2 matrix/TRC 프로파일은 `wtpt` 에 보정되지 않은 매체 흰색을 담아도
됩니다. 이 개발 기계에 설치된 시스템 sRGB 와 Adobe RGB 가 실제로 그렇습니다 — 둘 다 D65 를
담고 있고 `chad` 태그는 없습니다. 곧이곧대로 나누면 파랑이 1.32 로 나와 상한 1.2 에 걸리고,
**sRGB 를 프루프 목적지로 고르는 순간 화면 전체가 파래집니다.** macOS 에서는 나올 수 없는
결과입니다.

## 결정

**1. 소프트 프루프에 대응하는 내보내기 진입점을 만들지 않습니다.**

`nf_develop_preview_v23` 에는 프루프 인자가 있고, `nf_develop_export_v22` 에는 없습니다. 앞으로도
만들지 않습니다. 프루프는 현상 요청 struct 밖에 있으므로 내보내기가 읽을 필드 자체가 존재하지
않습니다. 규율이 아니라 구조로 막습니다.

**2. matrix/TRC RGB 프로파일의 D50 상대 흰색은 색소 합에서 얻습니다.**

색소는 정의상 PCS 흰색으로 합해집니다. 설치된 프로파일 넷을 실측한 결과 D65 를 선언한 둘을
포함해 전부 D50 에서 2e-4 안쪽으로 합해집니다.

**LUT 프로파일은 `wtpt` 를 그대로 씁니다.** 실제 인쇄·프레스 프로파일은 전부 LUT 이고, 그
`wtpt` 는 측정된 용지입니다 — 시뮬레이션을 의미 있게 만드는 바로 그 값이므로 정규화하면 기능이
사라집니다.

**3. 재구성 결과가 D50 에서 `1.0e-3` 안쪽이면 정확히 중립으로 스냅합니다.**

세 채널을 묶어서 판정합니다. 두 채널만 중립인 용지는 진짜 용지입니다.

## 결과

**설치된 RGB 출력 프로파일 넷으로 실촬영 네거티브를 렌더한 결과가 프루프 없는 렌더와 전부 바이트
동일합니다.** macOS 내장 프로파일이 내는 결과 — 아무 변화 없음 — 와 같습니다. 스냅이 없으면
eciRGB v2 와 WideGamutRGB 가 1 코드씩 움직입니다(실측).

**macOS 에 없는 코드가 두 군데 생겼습니다** — 색소 재구성과 스냅 허용치. 이것은 계산의 차이가
아니라 **입력이 만들어지는 경로의 차이를 메우는 것**이고, 그래서 macOS 가 실제로 내는 결과에
가까워집니다. 이 구분을 잃으면 다음 사람이 "macOS 에 없으니 지우자" 로 되돌립니다.

**프루프가 꺼져 있어도 affine 을 분기 없이 계산합니다.** scale 1 / bias 0 은 부동소수점에서
정확한 항등이라 결과가 같다는 것이 증명되고(위의 바이트 동일), 실측 비용은 82.4 ms 대비
82.1~83.8 ms 로 잡음 안입니다. 갈라질 수 있는 두 번째 경로를 만들지 않는 쪽을 택했습니다.

## 뒤집는 조건

**2번**: 색소 합이 D50 에서 멀리 떨어진 정상적인 matrix/TRC 프로파일이 실제로 발견되는 경우.
그때는 `chad` 태그를 우선 적용하는 규칙을 앞에 두어야 합니다(설치된 다섯 개에는 하나도 없어
지금은 근거가 없습니다).

**3번**: 스냅 허용치 안에 들어오는 진짜 용지가 나타나는 경우. 실제 용지는 12% 떨어져 있으므로
현재로서는 세 자릿수의 여유가 있습니다.

**1번은 뒤집지 않습니다.** 인화물에 보기용 시뮬레이션을 굽는 것은 요구사항이 아니라 결함입니다.
