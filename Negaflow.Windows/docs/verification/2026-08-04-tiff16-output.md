## 해석 제한

- ARM64는 compile/PE 증거만 있으며 실제 Windows ARM64에서 WIC TIFF encode/readback을 실행하지 않았습니다.
- readback은 같은 Microsoft WIC codec 계열이므로 독립 TIFF decoder 동등성 증거가 아닙니다.
- minimal allowlist는 현재 Windows WIC 출력에 맞춘 fail-closed 정책이며 servicing 차이를 모두 검증하지
  않았습니다.
- source observation은 file ID·크기·최종 수정 시각 비교이며 cryptographic content 동일성 증거가
  아닙니다.
- 현재 machine의 등록 sRGB profile을 사용하므로 machine 간 ICC byte 재현성을 입증하지 않습니다.
- 전체 working float와 packed RGB16을 함께 소유하므로 대형 이미지 memory 목표를 닫지 않았습니다.
- stage wall time만 기록하며 CPU time, canonical digest와 macOS TIFF/pixel diff는 아직 없습니다.
- exposure·contrast·curve 조합, optional metadata/DPI/compression과 catalog transaction은 미구현입니다.
